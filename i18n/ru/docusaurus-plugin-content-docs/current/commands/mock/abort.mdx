# abort

## Обзор {/* #overview */}

Используйте команду `abort`, чтобы прервать запрос.

В сессии WebDriver BiDi вызывайте `mock.abort()` без кода ошибки. В сессии CDP укажите одну из следующих ошибок:

-   Failed
-   Aborted
-   TimedOut
-   AccessDenied
-   ConnectionClosed | ConnectionReset | ConnectionRefused | ConnectionAborted | ConnectionFailed
-   NameNotResolved
-   InternetDisconnected
-   AddressUnreachable
-   BlockedByClient | BlockedByResponse

## Использование {/* #usage */}

```javascript
mock.abort(errorCode);
```

## Примеры использования {/* #examples */}

В примере используется WebDriver BiDi: кнопка `#reload` отправляет GET на `/api/items`, а `#source` показывает результат.

```javascript testplane=mock-abort fixture=matchers-network
const mock = await browser.mock("/api/items");
mock.abort();

for (let i = 0; i < 2; i++) {
    await browser.$("#reload").click();
    await expect(browser.$("#source")).toHaveText("Unavailable");
}
```

Для CDP можно указать причину сетевой ошибки:

```javascript testplane=mock-abort-cdp fixture=matchers-network transport=cdp
const mock = await browser.mock("**/api/items");
const reasons = [];
mock.on("fail", ({ errorReason }) => reasons.push(errorReason));
mock.abort("ConnectionRefused");

await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("Unavailable");
expect(reasons).toEqual(["ConnectionRefused"]);
```
