# clear

## Обзор {/* #overview */}

Используйте команду `clear`, чтобы сбросить всю информацию, хранящуюся в массиве `mock.calls`.

## Использование {/* #usage */}

```javascript
mock.clear();
```

## Примеры использования {/* #examples */}

В примере используется WebDriver BiDi: кнопка `#reload` отправляет GET на `/api/items`, а `#source` показывает результат.

```javascript testplane=mock-clear fixture=matchers-network
const mock = await browser.mock("/api/items");
await browser.$("#reload").click();
await mock.waitForResponse();

expect(mock.calls).toHaveLength(1);
mock.clear();
expect(mock.calls).toHaveLength(0);
```
