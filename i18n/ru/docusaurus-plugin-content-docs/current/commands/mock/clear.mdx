# clear

## Обзор {/* #overview */}

Используйте команду `clear`, чтобы сбросить всю информацию, хранящуюся в массиве `mock.calls`.

## Использование {/* #usage */}

```javascript
mock.clear();
```

## Примеры использования {/* #examples */}

Запишем переход в сессии WebDriver BiDi, очистим историю и снова откроем ту же страницу:

```javascript testplane=mock-clear-ru fixture=matchers-intercept
it("очищает историю и продолжает записывать запросы", async ({ browser }) => {
    const page = await browser.mock("/fixtures/matchers/tasks.html");
    await browser.url("/fixtures/matchers/tasks.html");
    await page.waitForResponse();

    // Мок записал один переход; очищаем историю, не удаляя сам мок.
    expect(page.calls).toHaveLength(1);
    page.clear();
    expect(page.calls).toHaveLength(0);

    // Со следующего перехода история начнется заново.
    await browser.url("/fixtures/matchers/tasks.html");
    await page.waitForResponse();
    expect(page.calls).toHaveLength(1);
});
```
