# restore

## Обзор {/* #overview */}

Используйте команду `restore`, чтобы выполнить все то же, что делает [mock.clear()](../clear), а также удалить любые поддельные возвращаемые значения или реализации.

## Использование {/* #usage */}

```javascript
mock.restore();
```

## Примеры использования {/* #examples */}

В примере используется WebDriver BiDi: кнопка `#reload` отправляет GET на `/api/items`, а `#source` показывает результат.

```javascript testplane=mock-restore fixture=matchers-network
const mock = await browser.mock("/api/items");
mock.respond({ source: "mocked" });
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("mocked");

await mock.restore();
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("original");
```
