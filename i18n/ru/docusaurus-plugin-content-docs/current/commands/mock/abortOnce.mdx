# abortOnce

## Обзор {/* #overview */}

Используйте команду `abortOnce`, чтобы прервать запрос один раз.

В сессии WebDriver BiDi вызывайте `mock.abortOnce()` без кода ошибки. В сессии CDP укажите одну из следующих ошибок:

-   Failed
-   Aborted
-   TimedOut
-   AccessDenied
-   ConnectionClosed | ConnectionReset | ConnectionRefused | ConnectionAborted | ConnectionFailed
-   NameNotResolved
-   InternetDisconnected
-   AddressUnreachable
-   BlockedByClient | BlockedByResponse

## Использование {/* #usage */}

```javascript
mock.abortOnce(errorCode);
```

## Примеры использования {/* #examples */}

На странице задач кнопка Reload запрашивает `/api/items`. Если первый запрос не удался, пользователь может попробовать снова. В сессии WebDriver BiDi:

```javascript testplane=mock-abort-once-ru fixture=matchers-intercept
it("дает повторить запрос после одной ошибки", async ({ browser }) => {
    const items = await browser.mock("/api/items");
    items.abortOnce();

    await browser.url("/fixtures/matchers/tasks.html");
    const reload = await browser.$("#reload");
    const source = await browser.$("#source");

    // Страница обрабатывает ошибку первого запроса и показывает сообщение.
    await reload.click();
    await expect(source).toHaveText("Unavailable");

    // При следующем нажатии запрос доходит до исходного ресурса.
    await reload.click();
    await expect(source).toHaveText("original");
});
```

Для CDP можно указать причину сетевой ошибки:

```javascript testplane=mock-abort-once-cdp-ru fixture=matchers-intercept transport=cdp
const assert = require("node:assert/strict");

it("разрешает второй переход на ту же страницу", async ({ browser }) => {
    const path = "/fixtures/matchers/todos.html";
    const page = await browser.mock("**/fixtures/matchers/todos.html");
    const failures = [];
    page.on("fail", ({ errorReason }) => failures.push(errorReason));
    page.abortOnce("Failed");

    // Chrome может вернуть ошибку перехода или показать страницу ошибки. Обрабатываем только ожидаемую ошибку.
    try {
        await browser.url(path);
    } catch (error) {
        if (!error.message.includes("ERR_FAILED")) throw error;
    }
    assert.deepEqual(failures, ["Failed"]);

    // Однократная ошибка исчерпана. Открываем тот же URL и читаем заголовок настоящей страницы.
    await browser.url(path);
    const title = await browser.getTitle();
    assert.equal(title, "Todo list");
    assert.deepEqual(failures, ["Failed"]);
});
```
