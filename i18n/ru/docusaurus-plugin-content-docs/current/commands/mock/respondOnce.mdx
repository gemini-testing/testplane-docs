# respondOnce

## Обзор {/* #overview */}

Используйте команду `respondOnce`, чтобы ответить один раз заданной перезаписью.

Вы можете вызвать `respondOnce` несколько раз подряд, тогда при запросах ответы будут использоваться в том же порядке, как были вызваны команды `respondOnce`.

Если вы используете только `respondOnce` и обратитесь к ресурсу большее количество раз, чем вызывали `respondOnce`, то после исчерпания поддельных данных, запрос начнет возвращать оригинальный ответ от ресурса.

<Admonition type="info">
    Читайте также рецепт «[Как отслеживать и перехватывать сетевые запросы и
    ответы][how-to-intercept-requests-and-responses]».
</Admonition>

## Использование {/* #usage */}

```javascript
mock.respondOnce(overwrites, { headers, statusCode, fetchResponse });
```

## Примеры использования {/* #examples */}

При каждом открытии страница запрашивает список задач. В этом примере WebDriver BiDi первые три запроса получают списки из очереди, а четвертый — исходный список сервера.

```javascript testplane=mock-respond-once-ru fixture=matchers-intercept
async function getTodoTitles(browser) {
    // Дожидаемся списка, полученного после этого перехода, и читаем задачи по порядку.
    const firstTodo = await browser.$("#todo-list li");
    await firstTodo.waitForExist();
    const items = await browser.$$("#todo-list li");
    return Promise.all(items.map(item => item.getText()));
}

it("возвращает ответы из очереди, а затем настоящий список", async ({ browser }) => {
    const todos = await browser.mock("/fixtures/matchers/todos.json", { method: "GET" });
    // Ставим в очередь одного мока три разных списка.
    todos.respondOnce([{ title: "3" }, { title: "2" }, { title: "1" }]);
    todos.respondOnce([{ title: "2" }, { title: "1" }]);
    todos.respondOnce([{ title: "1" }]);

    // Каждый переход отправляет один GET-запрос и забирает следующий список.
    const page = "/fixtures/matchers/todos.html";
    await browser.url(page);
    const firstList = await getTodoTitles(browser);
    expect(firstList).toEqual(["3", "2", "1"]);

    await browser.url(page);
    const secondList = await getTodoTitles(browser);
    expect(secondList).toEqual(["2", "1"]);

    await browser.url(page);
    const thirdList = await getTodoTitles(browser);
    expect(thirdList).toEqual(["1"]);

    // Подмен больше не осталось: страница отображает настоящий ответ ресурса.
    await browser.url(page);
    const originalList = await getTodoTitles(browser);
    expect(originalList).toEqual(["Original todo"]);
});
```
