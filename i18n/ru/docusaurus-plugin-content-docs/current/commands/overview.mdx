# Команды Testplane

## Обзор {/* #overview */}

<span id="обзор" />

Справочник описывает Testplane v9 и команды используемой им ветки WebdriverIO v9. Доступность команды зависит от браузера, протокола сессии и версии зависимости; условия указаны на страницах команд. Для старых версий используйте архив документации и [WebdriverIO v8](https://v8.webdriver.io/docs/api).

В Testplane нет неявных глобальных `browser`, `$` и `$$` из WDIO runner. Получайте `browser` из аргумента теста или через `this.browser` в обычной функции. Стрелочная функция не получает контекст `this` теста. Ищите элементы через `browser.$` и `browser.$$`.

## Пример {/* #examples */}

Оба теста открывают `/` относительно `baseUrl`. Тестовая страница должна содержать `h1` с текстом `Command examples`.

```javascript
const assert = require("node:assert/strict");

it("commands: use the browser fixture", async ({ browser }) => {
    await browser.url("/");
    assert.equal(await browser.$("h1").getText(), "Command examples");
});

it("commands: use this.browser with a regular function", async function () {
    await this.browser.url("/");
    assert.equal(await this.browser.$("h1").getText(), "Command examples");
});
```

## Границы справочника {/* #scope */}

Низкоуровневые команды WebDriver, BiDi и Appium не дублируются: см. [протоколы WebdriverIO](https://webdriver.io/docs/api/webdriver). Методы объектов `InitScript` и часов описаны на страницах [addInitScript](./browser/addInitScript.mdx) и [emulate](./browser/emulate.mdx), а не как отдельные команды браузера. Для внешних рецептов учитывайте различия версий и получения объекта `browser`.
