# waitUntil

## Обзор {/* #overview */}

Используйте команду `waitUntil`, чтобы дождаться соблюдения определенного условия на странице в браузере.

## Использование {/* #usage */}

```javascript
await browser.waitUntil(condition, { timeout, timeoutMsg, interval });
```

## Примеры использования {/* #examples */}

**example.html**

```html testplane-html=browser-wait-text
<div id="someText">I am some text</div>
<script>
    setTimeout(() => {
        document.querySelector("#someText").textContent = "I am now different";
    }, 250);
</script>
```

**waitUntil.js**

```javascript testplane=browser-wait-until fixture=browser-wait-text
it("waits for the text to change", async ({ browser }) => {
    await browser.waitUntil(
        async () => (await browser.$("#someText").getText()) === "I am now different",
        { timeout: 5000, timeoutMsg: "Expected the new text within 5 seconds" },
    );
});
```
