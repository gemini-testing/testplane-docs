# url

## Обзор {/* #overview */}

Используйте команду `url`, чтобы перейти по заданному URL-адресу в браузере.

Если в конфигурации указан [baseUrl][base-url], то он будет добавлен к параметру `url` с помощью метода Node.JS [url.resolve()][url-resolve].

Вызов `browser.url()` с тем же URL-адресом, что и в прошлый раз, вызовет перезагрузку страницы.

## Использование {/* #usage */}

```javascript
await browser.url(url);
```

## Примеры использования {/* #examples */}

**url.js**

```javascript testplane=browser-navigate fixture=browser-page
const assert = require("node:assert/strict");

await browser.url("/navigation");
assert.equal(new URL(await browser.getUrl()).pathname, "/navigation");
```

**baseUrlResolutions.js**

```javascript testplane=browser-resolve-url fixture=browser-page
const assert = require("node:assert/strict");

const { baseUrl } = await browser.getConfig();
const absolute = new URL("/frame", baseUrl).href;
await browser.url(absolute);
assert.equal(await browser.getUrl(), absolute);

await browser.url("relative");
assert.equal(await browser.getUrl(), new URL("relative", baseUrl).href);

await browser.url("/rootRelative");
assert.equal(await browser.getUrl(), new URL("/rootRelative", baseUrl).href);
```
