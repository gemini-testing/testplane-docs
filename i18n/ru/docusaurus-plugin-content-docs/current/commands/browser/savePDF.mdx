# savePDF

## Обзор {/* #overview */}

Используйте команду `savePDF`, чтобы сохранить в pdf-файл текущий контекст в браузере.

## Использование {/* #usage */}

```javascript
await browser.savePDF(filepath, {
    orientation,
    scale,
    background,
    width,
    height,
    top,
    bottom,
    left,
    right,
    shrinkToFit,
    pageRanges,
});
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-save-pdf fixture=browser-file
const assert = require("node:assert/strict");

it("writes the current page as a PDF", async ({ browser }) => {
    const fs = require("node:fs/promises");
    const path = `./artifacts/page-${browser.sessionId}.pdf`;
    await browser.savePDF(path);
    const file = await fs.readFile(path);
    assert.equal(file.subarray(0, 5).toString(), "%PDF-");
});
```
