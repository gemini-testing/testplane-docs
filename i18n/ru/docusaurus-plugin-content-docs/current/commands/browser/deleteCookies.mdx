# deleteCookies

## Обзор {/* #overview */}

Используйте команду `deleteCookies`, чтобы удалить все или конкретные _cookies_ для текущей страницы.

Чтобы удалить конкретные _cookies_, нужно указать имя _cookie_ в виде строки или список имен _cookies_ в виде массива строк.

## Использование {/* #usage */}

```javascript
await browser.deleteCookies(names);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-delete-cookies fixture=browser-page
const assert = require("node:assert/strict");

it("deletes named cookies or all cookies", async ({ browser }) => {
    await browser.setCookies([
        { name: "test", value: "123" },
        { name: "test2", value: "456" },
        { name: "test3", value: "789" },
    ]);
    const names = async () => (await browser.getCookies()).map(cookie => cookie.name).sort();
    assert.deepEqual(await names(), ["test", "test2", "test3"]);

    await browser.deleteCookies(["test3"]);
    assert.deepEqual(await names(), ["test", "test2"]);

    await browser.deleteCookies();
    assert.deepEqual(await names(), []);
});
```
