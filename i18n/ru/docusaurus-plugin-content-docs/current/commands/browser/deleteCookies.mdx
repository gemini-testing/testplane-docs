# deleteCookies

## Обзор {/* #overview */}

Используйте команду `deleteCookies`, чтобы удалить все или конкретные _cookies_ для текущей страницы.

Чтобы удалить конкретные _cookies_, нужно указать имя _cookie_ в виде строки или список имен _cookies_ в виде массива строк.

## Использование {/* #usage */}

```javascript
await browser.deleteCookies(names);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-delete-cookies-ru fixture=browser-page
const assert = require("node:assert/strict");

// Выводим только имена и значения: у cookie есть и другие поля, например domain, path и expiry.
const namesAndValues = cookies =>
    cookies
        .map(({ name, value }) => ({ name, value }))
        .sort((a, b) => a.name.localeCompare(b.name));

it("should delete cookies", async ({ browser }) => {
    const initial = [
        { name: "test", value: "123" },
        { name: "test2", value: "456" },
        { name: "test3", value: "789" },
    ];
    await browser.setCookies(initial);

    let cookies = await browser.getCookies();
    console.log(namesAndValues(cookies));
    // Вывод:
    // [
    //     { name: "test", value: "123" },
    //     { name: "test2", value: "456" },
    //     { name: "test3", value: "789" }
    // ]
    assert.deepEqual(namesAndValues(cookies), initial);

    // Удаляем только указанную cookie.
    await browser.deleteCookies(["test3"]);
    cookies = await browser.getCookies();
    console.log(namesAndValues(cookies));
    // Вывод:
    // [
    //     { name: "test", value: "123" },
    //     { name: "test2", value: "456" }
    // ]
    assert.deepEqual(namesAndValues(cookies), [initial[0], initial[1]]);

    await browser.deleteCookies();
    cookies = await browser.getCookies();
    console.log(cookies); // выведет: []
    assert.deepEqual(cookies, []);
});
```
