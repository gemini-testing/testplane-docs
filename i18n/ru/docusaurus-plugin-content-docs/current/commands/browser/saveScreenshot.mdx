# saveScreenshot

## Обзор {/* #overview */}

Используйте команду `saveScreenshot`, чтобы сохранить скриншот текущего контекста в браузере в png-файл.

Имейте в виду, что некоторые драйверы браузеров делают скриншоты всего документа (например, драйвер [Gecko][gecko] для Firefox), тогда как другие — только текущего окна просмотра (например, [Chromedriver][chromedriver] для Chrome).

## Использование {/* #usage */}

```javascript
await browser.saveScreenshot(filepath);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-save-screenshot fixture=browser-file
const assert = require("node:assert/strict");

it("writes a PNG screenshot of the current page", async ({ browser }) => {
    const fs = require("node:fs/promises");
    const path = `./artifacts/page-${browser.sessionId}.png`;
    await browser.saveScreenshot(path);
    const file = await fs.readFile(path);
    assert.equal(file.subarray(0, 8).toString("hex"), "89504e470d0a1a0a");
});
```
