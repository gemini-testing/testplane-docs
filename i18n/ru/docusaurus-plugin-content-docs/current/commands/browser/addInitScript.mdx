# addInitScript

## Обзор {/* #overview */}

Выполните функцию в новых документах текущей вкладки или окна до запуска скриптов страницы. Это позволяет подготовить значения до того, как приложение их прочитает. Функция также выполняется в дочерних фреймах этого верхнеуровневого контекста при их добавлении или переходе на другую страницу.

Скрипт регистрируется для вкладки или окна, текущих в момент вызова `addInitScript`. Он не распространяется автоматически на другие вкладки и окна, в том числе открытые позже. Чтобы использовать его там, переключитесь на нужную вкладку или окно и зарегистрируйте скрипт отдельно до перехода на страницу.

## Использование {/* #usage */}

`browser.addInitScript(script, ...args)`

## Параметры {/* #parameters */}

| **Параметр** | **Тип**     | **По умолчанию** | **Описание**                                                         |
| ------------ | ----------- | ---------------- | -------------------------------------------------------------------- |
| `script`     | `Function`  | Обязателен       | Функция для выполнения в браузере, без доступа к переменным Node.js. |
| `args`       | `unknown[]` | []               | Аргументы, сериализуемые в JSON и передаваемые функции.              |

## Результат {/* #result */}

`Promise<InitScript>`. Чтобы получить данные в Node.js, до навигации подпишитесь через `script.on("data", listener)`. Браузерная функция отправляет данные через свой последний аргумент `emit`. Подписка синхронная, а `script.remove()` возвращает промис.

## Ограничения {/* #limitations */}

Нужна сессия WebDriver BiDi (`webSocketUrl: true`). Зарегистрируйте функцию до навигации. После `await script.remove()` она не запустится в новых документах, но уже загруженная страница не изменится.

В `@testplane/webdriverio` 9.6.2 передавайте функцию, а не строку. В ее теле используйте обычные кавычки: шаблонные строки могут нарушить синтаксис внедряемого скрипта. Символы вне Latin-1 (например, кириллица) в коде функции или сериализованных аргументах могут помешать регистрации.

## Пример {/* #examples */}

На [тестовом сайте](../overview.mdx#run-examples) страница `/navigation` при загрузке выполняет `window.initialSeed = window.navigationSeed ?? null`. Тест проверяет, какое значение прочитал **скрипт страницы** до и после удаления инициализатора.

```javascript testplane=browser-add-init-script
const assert = require("node:assert/strict");

it("addInitScript: set a value before page scripts", async ({ browser }) => {
    const script = await browser.addInitScript(value => {
        window.navigationSeed = value;
    }, 42);

    try {
        await browser.url("/navigation");
        assert.equal(await browser.execute(() => window.initialSeed), 42);
    } finally {
        await script.remove();
    }

    await browser.url("/navigation");
    assert.equal(await browser.execute(() => window.initialSeed), null);
});
```
