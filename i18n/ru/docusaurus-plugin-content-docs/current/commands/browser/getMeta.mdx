# getMeta

## Обзор

Используйте команду `getMeta`, чтобы получить мета-информацию о тесте.

Если указать ключ, то команда возвращает значение для конкретного ключа.
Если ключ не указан, команда вернет объект со всей мета-информацией теста.

Для установки значений в мета-информации используйте команду [setMeta](../setMeta).

<Admonition type="info">
    Эта команда реализована внутри testplane, в [API WebDriverIO][webdriverio-api] её нет.
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.getMeta();
```

или

```javascript
await browser.getMeta(key);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-test-metadata-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should get metadata for the current test", async ({ browser }) => {
    await browser.setMeta("foo", "bar");
    await browser.url("/foo/bar?baz=qux");

    const val = await browser.getMeta("foo");
    console.log(val); // выведет: "bar"
    assert.equal(val, "bar");

    const url = await browser.getMeta("url");
    console.log(url); // полный URL, заканчивающийся на /foo/bar?baz=qux
    assert.equal(url, await browser.getUrl());

    const meta = await browser.getMeta();
    console.log(meta);
    // Пример для baseUrl http://example.com; результат может содержать и другие поля:
    // { foo: "bar", url: "http://example.com/foo/bar?baz=qux", ... }
    assert.equal(meta.foo, "bar");
    assert.equal(meta.url, url);
});
```
