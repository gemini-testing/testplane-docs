# switchWindow

## Обзор {/* #overview */}

Используйте команду `switchWindow`, чтобы перевести фокус на конкретную вкладку или конкретное окно.

## Использование {/* #usage */}

```javascript
await browser.switchWindow(urlOrTitleToMatch);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-switch-window-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should switch to another window", async ({ browser }) => {
    // Открываем исходную страницу.
    await browser.url("/original");

    // Открываем вторую страницу в новой вкладке.
    const newUrl = new URL("/frame", await browser.getUrl()).href;
    await browser.newWindow(newUrl, { type: "tab" });

    // Переключаемся обратно по части URL.
    await browser.switchWindow("/original");
    assert.equal(await browser.getTitle(), "Command examples");

    // Снова переключаемся, теперь по заголовку страницы.
    await browser.switchWindow("Frame");
    assert.equal(await browser.getUrl(), newUrl);
});
```
