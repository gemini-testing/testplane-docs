# actions

## Обзор {/* #overview */}

Используйте команду `actions`, чтобы выполнить несколько действий ввода в одном из виртуализируемых устройств в веб-браузере. Например для имитации масштабирования страницы. Больше подробной информации представлено в описании команды [action][action].

## Использование {/* #usage */}

```typescript
await browser.actions([action1, action2, ...]);
```

## Примеры использования {/* #examples */}

```typescript testplane=browser-actions-pinch-ru fixture=browser-pinch
const assert = require("node:assert/strict");

it("should run two touch actions together for a pinch zoom", async ({ browser }) => {
    // Каждый палец — отдельный сенсорный указатель со своим ID.
    const finger = id => browser.action("pointer", { id, parameters: { pointerType: "touch" } });
    const left = finger("left").move(160, 180).down().move(80, 180).up();
    const right = finger("right").move(200, 180).down().move(280, 180).up();

    // Отправляем обе последовательности вместе, чтобы развести пальцы одним жестом.
    await browser.actions([left, right]);
    assert.equal(await browser.$("output").getText(), "Spread");
});
```
