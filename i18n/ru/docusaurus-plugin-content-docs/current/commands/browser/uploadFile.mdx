# uploadFile

## Обзор {/* #overview */}

Используйте команду `uploadFile`, чтобы загрузить файл на _[Selenium Standalone][selenium-file]_ сервер или в браузер через его драйвер (например, [Chromedriver][chromedriver]).

<Admonition type="warning">
    Команда _uploadFile_ поддерживается только в том случае, если вы используете [Selenium
    Grid][selenium-grid] или [Chromedriver][chromedriver]. Это связано с тем, что она использует
    неофициальную особенность протокола, которая реализована в данный момент только в _Chrome_ и при
    запуске в [Selenium Grid][selenium-grid].
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.uploadFile(localPath);
```

## Примеры использования {/* #examples */}

Пример загружает локальный SVG через ChromeDriver, отправляет форму и проверяет имя файла в подтверждении.

```javascript testplane=browser-upload-file fixture=browser-page
const path = require("node:path");

it("should upload a file", async ({ browser }) => {
    await browser.url("/fixtures/browser/upload.html");

    const filePath = path.resolve("fixtures/site/browser/banner.svg");
    const remoteFilePath = await browser.uploadFile(filePath);

    await browser.$("#file-upload").setValue(remoteFilePath);
    await browser.$("#file-submit").click();

    const status = await browser.$("output");
    await browser.waitUntil(async () => (await status.getText()) === "Uploaded: banner.svg");
});
```
