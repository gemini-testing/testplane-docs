# getPuppeteer

## Обзор {/* #overview */}

Используйте команду `getPuppeteer`, чтобы получить инстанс [Puppeteer][puppeteer] браузера для последующего выполнения с его помощью специальных команд.

Команды Puppeteer возвращают промисы; используйте `await` внутри теста.

<Admonition type="warning">
Команда _getPuppeteer_ работает только при использовании _Chrome DevTools Protocol (CDP)_.

Читайте подробности в разделе «[Как использовать Chrome DevTools Protocol в testplane][how-to-use-cdp]».

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.getPuppeteer();
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-get-puppeteer-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should use Puppeteer on the current page", async ({ browser }) => {
    await browser.url("/");
    const url = await browser.getUrl();
    const puppeteerBrowser = await browser.getPuppeteer();

    // Переходим к Puppeteer и находим страницу, открытую Testplane.
    const metrics = await browser.call(async () => {
        const pages = await puppeteerBrowser.pages();
        const page = pages.find(page => page.url() === url);
        assert.equal(await page.title(), "Command examples");
        await page.setGeolocation({ latitude: 59.95, longitude: 30.31667 });

        return page.metrics();
    });

    // LayoutCount — число пересчётов макета; точное значение зависит от страницы.
    console.log(metrics.LayoutCount);
    assert.ok(Number.isInteger(metrics.LayoutCount) && metrics.LayoutCount >= 0);
    assert.ok(metrics.Nodes > 0);
});
```
