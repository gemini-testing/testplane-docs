# overwriteCommand

## Обзор {/* #overview */}

Используйте команду `overwriteCommand`, чтобы переопределить уже существующие команды браузера _(browser)_ или элемента _(element)_.

<Admonition type="info">
    Читайте также рецепт «[Как добавить свои команды][how-to-add-custom-commands]».
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.overwriteCommand(name, callback, elementScope);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-overwrite-command-ru fixture=browser-page
const assert = require("node:assert/strict");

describe("pause", () => {
    beforeEach(async ({ browser }) => {
        // Выводим длительность паузы и возвращаем её после выполнения исходной команды.
        await browser.overwriteCommand("pause", async function (origPauseFunction, ms) {
            console.log(`Sleeping for ${ms}`);
            await origPauseFunction(ms);
            return ms;
        });
    });

    it("should use the overwritten pause command", async ({ browser }) => {
        // Вызываем переопределённую команду.
        const duration = await browser.pause(100); // выведет: "Sleeping for 100"
        assert.equal(duration, 100);
    });
});
```
