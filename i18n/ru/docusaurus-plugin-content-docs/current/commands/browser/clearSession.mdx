# clearSession

## Обзор {/* #overview */}

Команда браузера, которая очищает состояние сессии (удаляет куки, очищает локальное и сессионное хранилища).

## Использование {/* #usage */}

```javascript
await browser.clearSession();
```

## Примеры использования {/* #examples */}

```typescript testplane=browser-clear-session fixture=browser-page
const assert = require("node:assert/strict");

it("clears cookies and both web storages", async ({ browser }) => {
    await browser.url("/");
    await browser.setCookies({ name: "theme", value: "dark" });
    await browser.execute(() => {
        localStorage.setItem("theme", "dark");
        sessionStorage.setItem("draft", "hello");
    });

    await browser.clearSession();
    assert.deepEqual(await browser.getCookies(), []);
    assert.deepEqual(
        await browser.execute(() => [localStorage.length, sessionStorage.length]),
        [0, 0],
    );
});
```
