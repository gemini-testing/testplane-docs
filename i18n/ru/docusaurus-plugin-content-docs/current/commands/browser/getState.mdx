# getState

<Version version="8.40.0" />

## Обзор {/* #overview */}

Эта команда возвращает состояние страницы из файла, ранее сохраненного с помощью команды [saveState][saveState].

## Использование {/* #usage */}

```typescript testplane=browser-get-state-file fixture=browser-saved-state
import type { SaveStateData } from "testplane";
const assert = require("node:assert/strict");

const stateDump: SaveStateData = await browser.getState({
    path: "./artifacts/stateDump.json",
});
const theme = stateDump.cookies?.find(cookie => cookie.name === "theme");
assert.equal(theme?.value, "dark");
```

## Usage Examples {/* #examples */}

Прочитайте сохраненное состояние, не меняя текущую сессию.

```typescript testplane=browser-read-saved-state fixture=browser-page
const assert = require("node:assert/strict");

it("should read a saved session without restoring it", async ({ browser }) => {
    await browser.setCookies({ name: "theme", value: "dark" });
    const path = "./artifacts/stateDump.json";
    const saved = await browser.saveState({ path });
    await browser.clearSession();

    const stateData = await browser.getState({ path });
    assert.deepEqual(stateData, saved);
    assert.deepEqual(await browser.getCookies(), []);
});
```
