# getState

<Version version="8.40.0" />

## Обзор {/* #overview */}

Эта команда возвращает состояние страницы из файла, ранее сохраненного с помощью команды [saveState][saveState].

## Использование {/* #usage */}

```typescript testplane=browser-get-state-file fixture=browser-saved-state
const assert = require("node:assert/strict");

import type { SaveStateData } from "testplane";

const state: SaveStateData = await browser.getState({
    path: `./artifacts/demo-${browser.sessionId}.json`,
});
assert.equal(state.cookies?.find(cookie => cookie.name === "theme")?.value, "dark");
```

## Usage Examples {/* #examples */}

Прочитайте сохраненное состояние, не меняя текущую сессию.

```typescript testplane=browser-read-saved-state fixture=browser-page
const assert = require("node:assert/strict");

it("reads a previously saved session", async ({ browser }) => {
    await browser.setCookies({ name: "theme", value: "dark" });
    const path = `./artifacts/demo-${browser.sessionId}.json`;
    const saved = await browser.saveState({ path });
    const state = await browser.getState({ path });
    assert.deepEqual(state, saved);
});
```
