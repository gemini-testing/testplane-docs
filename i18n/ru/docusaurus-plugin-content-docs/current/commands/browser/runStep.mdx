# runStep

## Обзор {/* #overview */}

Используйте команду `runStep`, чтобы получить человекочитаемую историю выполнения теста, которая, в том числе, автоматически будет отображаться в [html-reporter][reporter].
Шаги могут быть вложенными.

## Использование {/* #usage */}

```typescript
await browser.runStep(stepName, stepCb);
```

## Примеры использования {/* #examples */}

```typescript testplane=browser-nested-steps fixture=browser-page
const assert = require("node:assert/strict");

it("keeps the missing element error from a nested step", async ({ browser }) => {
    await browser.runStep("prepare page", async () => {
        await browser.url("/");
        await browser.setCookies({ name: "cart", value: "empty" });
    });

    await assert.rejects(
        () =>
            browser.runStep("make an order", async () => {
                await browser.runStep("navigate to the shopping cart", async () => {
                    await browser.$("not-exist-selector").click();
                });
            }),
        /not-exist-selector/,
    );
});
```

Проверка ожидает ошибку об отсутствующем элементе. Без `assert.rejects` ошибка прервала бы тест. Вложенные шаги показывают в отчете, где она возникла:

```
- testplane: init browser
- prepare page
- make an order
    - navigate to the shopping cart
        - $("not-exist-selector")
        - click()
            - waitForExist
```

В этом примере шаг `prepare page` свернут, т.к. он был выполнен успешно.

Также, вы можете вернуть конкретное значение из шага.

```typescript testplane=browser-step-result fixture=browser-page
const assert = require("node:assert/strict");

const parsedPage = await browser.runStep("parse page", async () => {
    const heading = await browser.$("h1").getText();
    return { heading };
});

assert.equal(parsedPage.heading, "Command examples");
```
