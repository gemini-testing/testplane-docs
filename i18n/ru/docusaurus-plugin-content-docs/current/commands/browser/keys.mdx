# keys

## Обзор {/* #overview */}

Используйте команду `keys`, чтобы отправить последовательность нажатий клавиш в активный элемент.

Вы можете также использовать символы «Левая стрелка» или «Правая стрелка». Они будут автоматически преобразованы в соответствующие unicode-символы. Все поддерживаемые символы вы можете посмотреть [здесь][keyboard-actions].

Модификаторы типа `Ctrl`, `Shift`, `Alt` и `Meta` остаются нажатыми, пока вы сами не освободите их повторным вызовом. Однако модификация клика требует использования метода [performActions][perform-actions] из _WebDriver Actions API_.

## Использование {/* #usage */}

```javascript
await browser.keys(value);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-keys-ru fixture=browser-clipboard
const assert = require("node:assert/strict");

it("copies text out of the active element", async ({ browser }) => {
    const modifier = browser.capabilities.platformName.toLowerCase().includes("mac")
        ? "Meta"
        : "Control";

    // Выделяем и копируем текст из поля ввода.
    const username = await browser.$("#username");
    await username.setValue("anonymous");
    await browser.keys([modifier, "a"]);
    await browser.keys([modifier, "c"]);

    // Вставляем в другое поле и проверяем, что именно скопировалось.
    const copy = await browser.$("#copy");
    await copy.click();
    await browser.keys([modifier, "v"]);
    assert.equal(await copy.getValue(), "anonymous");

    // Строка вместо сочетания клавиш заменяет выделенный текст.
    await browser.keys([modifier, "a"]);
    await browser.keys("guest");
    assert.equal(await copy.getValue(), "guest");
});
```
