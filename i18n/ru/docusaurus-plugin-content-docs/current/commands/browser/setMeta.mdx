# setMeta

## Обзор

Используйте команду `setMeta`, чтобы записать значение под заданным ключом в мета-информацию теста.

Для чтения мета-информации используйте команду [getMeta](../getMeta).

<Admonition type="info">
    Эта команда реализована внутри testplane, в [API WebDriverIO][webdriverio-api] её нет.
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.setMeta(key, value);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-test-metadata fixture=browser-page
const assert = require("node:assert/strict");

it("reads a custom field and the last navigation from test metadata", async ({ browser }) => {
    await browser.setMeta("foo", "bar");
    await browser.url("/foo/bar?baz=qux");
    assert.equal(await browser.getMeta("foo"), "bar");
    assert.equal(await browser.getMeta("url"), await browser.getUrl());

    const meta = await browser.getMeta();
    assert.equal(meta.foo, "bar");
    assert.equal(new URL(meta.url).search, "?baz=qux");
});
```
