# call

## Обзор {/* #overview */}

Используйте команду `call` для выполнения любого асинхронного действия в тестах.

Сама команда при этом обрабатывается как синхронная функция. Она принимает промис и останавливает свое выполнение до тех пор, пока промис не будет выполнен.

## Использование {/* #usage */}

```javascript
await browser.call(callback);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-call-ru fixture=browser-page
const assert = require("node:assert/strict");

const http = require("node:http");

it("should wait for asynchronous Node.js APIs", async ({ browser }) => {
    await browser.url("/");
    const url = new URL("/api/items", await browser.getUrl());

    // Если сторонняя библиотека возвращает промис, верните его из колбэка.
    // Например, так тест может подготовить свои данные в бэкенде или БД.
    // Здесь мы получаем тестовые данные с бэкенда через fetch.
    const data = await browser.call(async () => {
        const response = await fetch(url);
        return response.json();
    });
    assert.equal(data.source, "original");

    // Если библиотека поддерживает только колбэк, оберните вызов в Promise.
    // Вызовите resolve при получении ответа или reject при ошибке.
    const status = await browser.call(() => {
        return new Promise((resolve, reject) => {
            const request = http.get(url, response => {
                response.resume();
                resolve(response.statusCode);
            });
            request.on("error", reject);
        });
    });
    assert.equal(status, 200);
});
```
