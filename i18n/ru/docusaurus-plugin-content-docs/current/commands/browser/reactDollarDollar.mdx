# react$$

## Обзор {/* #overview */}

Используйте команду `react$$`, чтобы найти на странице множество React-компонентов по их настоящему имени, одновременно фильтруя их по props'ам и состоянию.

<Admonition type="warning">
Команда _react$_ работает только в приложениях, которые используют _React v16.x._

Читайте больше о React-селекторах в рецепте «[Как использовать селекторы][how-to-use-selectors]».

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.react$$(reactComponentSelector, { props, state });
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-react-components-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should find the orange operator buttons", async ({ browser }) => {
    await browser.url("/fixtures/browser/calculator16.html");

    const orangeButtons = await browser.react$$("Button", {
        props: { orange: true },
    });

    const labels = await Promise.all(Array.from(orangeButtons, button => button.getText()));
    console.log(labels); // выведет: ["÷", "x", "-", "+", "="]
    assert.deepEqual(labels, ["÷", "x", "-", "+", "="]);
});
```
