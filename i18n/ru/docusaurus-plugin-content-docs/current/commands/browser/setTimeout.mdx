# setTimeout

## Обзор {/* #overview */}

Используйте команду `setTimeout`, чтобы настроить таймауты для поиска элемента на странице, ожидания загрузки документа и выполнения скриптов через команды [execute][execute] или [executeAsync][execute-async].

## Использование {/* #usage */}

```javascript
await browser.setTimeout({ implicit, pageLoad, script });
```

## Параметры команды {/* #parameters */}

<table>
<thead>
<tr><td>**Имя**</td><td>**Тип**</td><td>**Описание**</td></tr>
</thead>
<tbody>
<tr><td>implicit</td><td>Number</td><td>Время в миллисекундах для повторной попытки определения местоположения элемента при поиске элемента.</td></tr>
<tr><td>pageLoad</td><td>Number</td><td>Время ожидания загрузки документа, в миллисекундах.</td></tr>
<tr><td>script</td><td>Number</td><td>Таймаут для скриптов, запущенных с помощью [execute][execute] или [executeAsync][execute-async]. Задается в миллисекундах.</td></tr>

</tbody>
</table>

## Примеры использования {/* #examples */}

```javascript testplane=browser-set-timeout-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should change timeouts before running a long script", async ({ browser }) => {
    await browser.setTimeout({
        pageLoad: 10000,
        script: 5000,
    });

    // Скрипт завершается асинхронно, до истечения нового таймаута.
    const message = await browser.executeAsync(done => {
        setTimeout(() => done("Wake me up before you go!"), 1000);
    });
    assert.equal(message, "Wake me up before you go!");

    const timeouts = await browser.getTimeouts();
    assert.equal(timeouts.pageLoad, 10000);
    assert.equal(timeouts.script, 5000);
});
```
