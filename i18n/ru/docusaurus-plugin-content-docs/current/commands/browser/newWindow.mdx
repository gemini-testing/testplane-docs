# newWindow

## Обзор {/* #overview */}

Используйте команду `newWindow`, чтобы открыть новое окно в браузере.

Эта команда эквивалентна функции [window.open()][window-open].

Обратите внимание, что при выполнении эта команда автоматически переключит вас в новое окно.

<Admonition type="warning">Команда _newWindow_ не работает в мобильных окружениях (!)</Admonition>

Используйте `{ type: "tab" }` для вкладки и `{ type: "window" }` для окна. Параметры `windowName` и `windowFeatures` поддерживаются только в WebDriver Classic.

## Использование {/* #usage */}

```javascript
await browser.newWindow(url, { windowName, windowFeatures });
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-new-window fixture=browser-page
const assert = require("node:assert/strict");

it("opens a new tab and returns to the original one", async ({ browser }) => {
    await browser.url("/");
    const original = await browser.getWindowHandle();
    const frameUrl = new URL("/frame", await browser.getUrl()).href;
    await browser.newWindow(frameUrl, { type: "tab" });
    assert.equal(await browser.getTitle(), "Frame");

    await browser.closeWindow();
    await browser.switchToWindow(original);
    assert.equal(await browser.getTitle(), "Command examples");
});
```
