# mockRestoreAll

## Обзор {/* #overview */}

Используйте команду `mockRestoreAll`, чтобы восстановить информацию и поведение в зарегистрированных имитациях до их создания. Имитации регистрируются с помощью команды [mock][mock].

## Использование {/* #usage */}

```typescript
await browser.mockRestoreAll();
```

## Примеры использования {/* #examples */}

```typescript testplane=browser-mock-restore-all fixture=browser-mock
const assert = require("node:assert/strict");

it("removes response overrides for both requests", async ({ browser }) => {
    const items = await browser.mock("/api/items");
    const other = await browser.mock("/api/other");
    await items.respond({ source: "fixture" });
    await other.respond({ source: "fixture" });

    const sources = () =>
        browser.execute(async () => {
            const responses = await Promise.all([fetch("/api/items"), fetch("/api/other")]);
            return Promise.all(responses.map(async response => (await response.json()).source));
        });
    assert.deepEqual(await sources(), ["fixture", "fixture"]);

    await browser.mockRestoreAll();
    assert.deepEqual(await sources(), ["original", "redirected"]);
});
```
