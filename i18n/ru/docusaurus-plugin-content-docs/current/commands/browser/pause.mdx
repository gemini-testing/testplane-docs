# pause

## Обзор {/* #overview */}

Используйте команду `pause`, чтобы приостановить выполнение теста на заданный промежуток времени.

<Admonition type="warning">
    Не рекомендуется использовать эту команду для ожидания отображения элемента. Чтобы избежать
    ложных результатов тестирования, лучше использовать такие команды, как
    [waitForExist][wait-for-exist] или другие команды _waitFor*_.
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.pause(milliseconds);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-pause-ru fixture=browser-page
const assert = require("node:assert/strict");

it("should pause the execution", async ({ browser }) => {
    const startTime = Date.now();
    await browser.pause(1000);
    const endTime = Date.now();

    const elapsed = endTime - startTime;
    console.log(elapsed); // около 1000 мс; планировщик может прибавить задержку
    assert.ok(elapsed >= 999);
});
```
