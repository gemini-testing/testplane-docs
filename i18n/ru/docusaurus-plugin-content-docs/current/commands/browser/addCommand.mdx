# addCommand

## Обзор {/* #overview */}

Используйте команду `addCommand`, чтобы добавить свою команду к браузеру _(browser)_ или к элементу _(element)_. Добавляемая команда может быть как синхронной, так и асинхронной.

<Admonition type="info">
    Подробнее о том, как добавлять свои кастомные команды, читайте в рецепте «[Как добавить свои
    команды][how-to-add-custom-commands]».
</Admonition>

## Использование {/* #usage */}

```javascript
browser.addCommand(name, callback, elementScope);
```

## Примеры использования {/* #examples */}

```javascript testplane=browser-add-command fixture=browser-page
const assert = require("node:assert/strict");

it("gets the title and URL with a custom command", async ({ browser }) => {
    browser.addCommand("getUrlAndTitle", async function (customParam) {
        return { url: await this.getUrl(), title: await this.getTitle(), customParam };
    });
    await browser.url("/");
    const result = await browser.getUrlAndTitle("foobar");
    assert.equal(result.url, await browser.getUrl());
    assert.equal(result.title, "Command examples");
    assert.equal(result.customParam, "foobar");
});
```
