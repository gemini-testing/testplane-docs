# mockClearAll

## Обзор {/* #overview */}

Используйте команду `mockClearAll`, чтобы сбросить всю сохраненную информацию в зарегистрированных имитациях. Имитации регистрируются с помощью команды [mock][mock].

## Использование {/* #usage */}

```typescript
await browser.mockClearAll();
```

## Примеры использования {/* #examples */}

```typescript testplane=browser-mock-clear-all-ru fixture=browser-mock
const assert = require("node:assert/strict");

it("should clear all mocks", async ({ browser }) => {
    const docMock = await browser.mock("/frame");
    const jsMock = await browser.mock("/fixtures/browser/banner.js");
    const calls = () => [docMock.calls.length, jsMock.calls.length];

    await browser.url("/fixtures/browser/resources.html");
    const load = await browser.$("button");

    await load.click();
    await browser.waitUntil(async () => (await browser.$("output").getText()) === "1");
    assert.deepEqual(calls(), [1, 1]); // оба ресурса были запрошены

    await load.click();
    await browser.waitUntil(async () => (await browser.$("output").getText()) === "2");
    assert.deepEqual(calls(), [2, 1]); // браузер повторно использует уже загруженный JS-модуль

    await browser.mockClearAll();
    assert.deepEqual(calls(), [0, 0]); // обе истории запросов очищены
    await browser.mockRestoreAll();
});
```
