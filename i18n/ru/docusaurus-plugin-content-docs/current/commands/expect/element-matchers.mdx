# expect для элементов

## toBeDisplayed

Вызывает [isDisplayed](../../element/isDisplayed) на заданном элементе.

Например:

```javascript testplane=expect-to-be-displayed fixture=matchers-page
const input = await browser.$("#username");
await expect(input).toBeDisplayed();
```

## toBeFocused

Проверяет, есть ли фокус на элементе. Это утверждение работает только в веб-контексте.

Например:

```javascript testplane=expect-to-be-focused fixture=matchers-page

await expect(input).toBeFocused();
```

## toHaveText

Проверяет, совпадает ли текст элемента с заданным значением.

Также может быть вызван с массивом в качестве параметра в случае, когда элемент может иметь разные тексты.

Например:

```javascript testplane=expect-to-have-text fixture=matchers-page
const elem = await browser.$("h1");
await expect(elem).toHaveText("Task list");
await expect(elem).toHaveText(["Task list", "No tasks yet"]);
```

## toHaveTextContaining

Проверяет, содержит ли текст элемента заданное значение в качестве подтекста.

Также может быть вызван с массивом в качестве параметра в случае, когда элемент может иметь разные тексты.

Например:

```javascript testplane=expect-to-have-text-containing fixture=matchers-page
const elem = await browser.$("h1");
await expect(elem).toHaveTextContaining("Task");
await expect(elem).toHaveTextContaining(["Task", "No tasks"]);
```

## toHaveChildren

Проверяет количество дочерних элементов заданного элемента, используя команду [element.$('./\*')](../../element/_dollardollar).

Передавайте объект опций: в используемой версии expect-webdriverio вызов без аргументов завершается ошибкой. Пустой объект означает «хотя бы один дочерний элемент».

Например:

```javascript testplane=expect-to-have-children fixture=matchers-page
const list = await browser.$("ul");
await expect(list).toHaveChildren({});
await expect(list).toHaveChildren({ gte: 1 });
```

```javascript testplane=expect-to-have-children-count fixture=matchers-page
const list = await browser.$("ul");
await expect(list).toHaveChildren(3);
await expect(list).toHaveChildren({ eq: 3 });
```

## toBeElementsArrayOfSize

Проверяет количество полученных элементов с помощью команды [$$](../../element/_dollardollar).

Например:

```javascript testplane=expect-to-be-elements-array-of-size fixture=matchers-page
const listItems = await browser.$$("ul > li");
await expect(listItems).toBeElementsArrayOfSize(3);
```

```javascript testplane=expect-to-be-elements-array-of-size-limit fixture=matchers-page
const listItems = await browser.$$("ul > li");
await expect(listItems).toBeElementsArrayOfSize({ lte: 10 });
```
