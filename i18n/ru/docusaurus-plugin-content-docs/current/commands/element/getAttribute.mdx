# getAttribute

## Обзор {/* #overview */}

Используйте команду `getAttribute`, чтобы получить атрибут из DOM-элемента на основе имени атрибута.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getAttribute(attributeName);
```

## Параметры команды {/* #parameters */}

<table>

<tr><td>**Имя**</td><td>**Тип**</td><td>**Описание**</td></tr>
</thead>

</tbody>
</table>

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<form action="/submit" method="post" class="loginForm">
    <input type="text" name="name" placeholder="username" />
    <input type="password" name="password" placeholder="password" />
    <input type="submit" value="Submit" />
</form>
```

```javascript testplane=element-get-attribute fixture=element-html
const assert = require("node:assert/strict");

const form = await browser.$("form");
assert.equal(await form.getAttribute("method"), "post");
```
