# getComputedRole

## Обзор {/* #overview */}

Используйте команду `getComputedRole`, чтобы получить вычисленную [WAI-ARIA][wai-aria] роль элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getComputedRole();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<select name="q" aria-label="Search">
    <option>All</option>
</select>
```

```javascript testplane=element-get-computed-role-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getComputedRole command", async ({ browser }) => {
    const elem = await browser.$('[name="q"]');
    const role = await elem.getComputedRole();
    console.log(role); // выведет: "combobox"
    assert.equal(role, "combobox");
});
```

[wai-aria]: https://ru.wikipedia.org/wiki/WAI-ARIA
