# isClickable

## Обзор {/* #overview */}

Используйте команду `isClickable`, чтобы определить, можно ли кликнуть по заданному DOM-элементу.

Команда возвращает `true`, если выбранный DOM-элемент:

-   существует
-   видимый
-   находится внутри вьюпорта (если нет, то попробуйте сделать подскролл к элементу)
-   центр элемента не перекрыт другим элементом
-   элемент не отключен _(not disabled)_

иначе команда возвращает `false`.

<Admonition type="warning">
Команда _isClickable_ работает только в веб-браузере и в контексте _webview_ мобильных приложений.

Команда не работает в нативном контексте мобильных приложений.

Кроме того, в отличие от других команд элемента, testplane не будет дожидаться существования элемента, чтобы выполнить эту команду.

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).isClickable();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<button id="enable" onclick="document.querySelector('#save').disabled = false">Enable save</button>
<button id="save" disabled onclick="this.disabled = true">Save</button>
```

```javascript testplane=element-is-clickable-ru fixture=element-html
const assert = require("node:assert/strict");

it("should detect if an element is clickable", async ({ browser }) => {
    const save = await browser.$("#save");
    let clickable = await save.isClickable();
    console.log(clickable); // выведет: false
    assert.equal(clickable, false);

    await browser.$("#enable").click();
    // Ждем, когда на кнопку Save можно будет кликнуть.
    await browser.waitUntil(() => save.isClickable());
    clickable = await save.isClickable();
    console.log(clickable); // выведет: true
    assert.equal(clickable, true);
});
```
