# dragAndDrop

## Обзор {/* #overview */}

Используйте команду `dragAndDrop`, чтобы перетащить элемент в указанный элемент назначения или позицию.

## Использование {/* #usage */}

```javascript
await browser.$(selector).dragAndDrop(target, { duration });
```

## Параметры команды {/* #parameters */}

## Примеры использования {/* #examples */}

Перетащим плитку на цель того же размера, а затем сдвинем на 100 пикселей вправо и на 200 вниз.

```javascript testplane=element-drag-and-drop fixture=element-drag
const assert = require("node:assert/strict");

const tile = await browser.$("#someElem");
const target = await browser.$("#someTarget");
await tile.dragAndDrop(target);
assert.deepEqual(await tile.getLocation(), await target.getLocation());

const { x, y } = await tile.getLocation();
await tile.dragAndDrop({ x: 100, y: 200 });
assert.deepEqual(await tile.getLocation(), { x: x + 100, y: y + 200 });
```
