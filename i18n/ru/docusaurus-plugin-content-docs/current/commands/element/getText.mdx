# getText

## Обзор {/* #overview */}

Используйте команду `getText`, чтобы получить текстовое содержимое из DOM-элемента.

Убедитесь, что элемент, из которого вы хотите запросить текст, является [интерактивным][interactable], иначе команда вернет вам пустую строку. Если элемент отключен _(disabled)_ или не виден _(not visible)_, и вы все еще хотите получить его текстовое содержимое, воспользуйтесь командой [getHTML](../getHTML) в качестве обходного пути.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getText();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div id="elem">
    Lorem ipsum <strong>dolor</strong> sit amet,<br />
    consetetur sadipscing elitr
</div>
<span style="display: none">I am invisible</span>
```

```javascript testplane=element-get-text fixture=element-html
const assert = require("node:assert/strict");

const text = await browser.$("#elem").getText();
assert.equal(text, "Lorem ipsum dolor sit amet,\nconsetetur sadipscing elitr");
assert.equal(await browser.$("span").getText(), "");
```

Чтобы прочитать третий столбец второй строки:

```html testplane-html=element-table
<table id="table1">
    <tr>
        <th>First name</th>
        <th>Last name</th>
        <th>Email</th>
    </tr>
    <tr>
        <td>John</td>
        <td>Doe</td>
        <td>john@example.com</td>
    </tr>
</table>
```

```javascript testplane=element-get-text-table fixture=element-table
const assert = require("node:assert/strict");

const rows = await browser.$$("#table1 tr");
const columns = await rows[1].$$("td");
assert.equal(await columns[2].getText(), "john@example.com");
```

[interactable]: https://www.w3.org/TR/webdriver/#interactability
