# getText

## Обзор {/* #overview */}

Используйте команду `getText`, чтобы получить текстовое содержимое из DOM-элемента.

Убедитесь, что элемент, из которого вы хотите запросить текст, является [интерактивным][interactable], иначе команда вернет вам пустую строку. Если элемент отключен _(disabled)_ или не виден _(not visible)_, и вы все еще хотите получить его текстовое содержимое, воспользуйтесь командой [getHTML](../getHTML) в качестве обходного пути.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getText();
```

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<div id="elem">
    Lorem ipsum <strong>dolor</strong> sit amet,<br />
    consetetur sadipscing elitr
</div>
<span style="display: none">I am invisible</span>
```

**getText.js**

```javascript testplane=element-get-text-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getText function", async ({ browser }) => {
    const elem = await browser.$("#elem");
    const text = await elem.getText();
    console.log(text);
    // выведет:
    // Lorem ipsum dolor sit amet,
    // consetetur sadipscing elitr
    assert.equal(text, "Lorem ipsum dolor sit amet,\nconsetetur sadipscing elitr");

    const hidden = await browser.$("span");
    const hiddenText = await hidden.getText();
    console.log(hiddenText); // выведет: "" (пустую строку), потому что элемент скрыт
    assert.equal(hiddenText, "");
});
```

Чтобы прочитать третий столбец второй строки:

```html testplane-html=element-table
<table id="table1">
    <tr>
        <th>First name</th>
        <th>Last name</th>
        <th>Email</th>
    </tr>
    <tr>
        <td>John</td>
        <td>Doe</td>
        <td>john@example.com</td>
    </tr>
</table>
```

```javascript testplane=element-get-text-table-ru fixture=element-table
const assert = require("node:assert/strict");

it("get content from table cell", async ({ browser }) => {
    const rows = await browser.$$("#table1 tr");
    const columns = await rows[1].$$("td"); // Получаем ячейки второй строки.

    const text = await columns[2].getText(); // Получаем текст из третьего столбца.
    console.log(text); // выведет: "john@example.com"
    assert.equal(text, "john@example.com");
});
```

[interactable]: https://www.w3.org/TR/webdriver/#interactability
