# nextElement

## Обзор {/* #overview */}

Используйте команду `nextElement`, чтобы получить следующий дочерний элемент выбранного DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).nextElement();
```

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

**nextElement.js**

```javascript testplane=element-next-element-ru fixture=element-html
const assert = require("node:assert/strict");

it("should get text from next sibling element", async ({ browser }) => {
    const paragraphs = await browser.$$("p");
    const nextElement = await paragraphs[1].nextElement();

    const text = await nextElement.getText();
    console.log(text); // выведет: "Sibling Three"
    assert.equal(text, "Sibling Three");
});
```
