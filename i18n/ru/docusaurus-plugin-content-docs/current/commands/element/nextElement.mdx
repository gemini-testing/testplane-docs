# nextElement

## Обзор {/* #overview */}

Используйте команду `nextElement`, чтобы получить следующий дочерний элемент выбранного DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).nextElement();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

```javascript testplane=element-next-element fixture=element-html
const assert = require("node:assert/strict");

const paragraphs = await browser.$$("p");
const sibling = await paragraphs[1].nextElement();
assert.equal(await sibling.getText(), "Sibling Three");
```
