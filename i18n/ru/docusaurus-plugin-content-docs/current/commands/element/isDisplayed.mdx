# isDisplayed

## Обзор {/* #overview */}

Используйте команду `isDisplayed`, чтобы определить, отображается ли заданный DOM-элемент.

Команда возвращает `true`, если выбранный DOM-элемент отображается, иначе возвращает `false`.

<Admonition type="warning">
    В отличие от других команд элемента, testplane не будет дожидаться существования элемента, чтобы
    выполнить эту команду.
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).isDisplayed();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div id="visible">Visible</div>
<div id="notDisplayed" style="display: none">Hidden</div>
<div id="notVisible" style="visibility: hidden">Hidden</div>
<div id="notInViewport" style="position: absolute; left: 10000px">Off screen</div>
<div id="zeroOpacity" style="opacity: 0">Transparent</div>
```

```javascript testplane=element-is-displayed fixture=element-html
const assert = require("node:assert/strict");

assert.equal(await browser.$("#visible").isDisplayed(), true);
assert.equal(await browser.$("#notDisplayed").isDisplayed(), false);
assert.equal(await browser.$("#notVisible").isDisplayed(), false);
assert.equal(await browser.$("#notExisting").isDisplayed(), false);
assert.equal(await browser.$("#notInViewport").isDisplayed(), true);
assert.equal(await browser.$("#zeroOpacity").isDisplayed(), false);
```
