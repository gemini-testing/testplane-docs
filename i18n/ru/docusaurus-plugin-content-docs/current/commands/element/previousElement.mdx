# previousElement

## Обзор {/* #overview */}

Используйте команду `previousElement`, чтобы получить предыдущий дочерний элемент выбранного DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).previousElement();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

```javascript testplane=element-previous-element fixture=element-html
const assert = require("node:assert/strict");

const paragraphs = await browser.$$("p");
const sibling = await paragraphs[1].previousElement();
assert.equal(await sibling.getText(), "Sibling One");
```
