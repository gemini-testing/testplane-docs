# previousElement

## Обзор {/* #overview */}

Используйте команду `previousElement`, чтобы получить предыдущий дочерний элемент выбранного DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).previousElement();
```

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

**previousElement.js**

```javascript testplane=element-previous-element-ru fixture=element-html
const assert = require("node:assert/strict");

it("should get text from previous sibling element", async ({ browser }) => {
    const paragraphs = await browser.$$("p");
    const previousElement = await paragraphs[1].previousElement();

    const text = await previousElement.getText();
    console.log(text); // выведет: "Sibling One"
    assert.equal(text, "Sibling One");
});
```
