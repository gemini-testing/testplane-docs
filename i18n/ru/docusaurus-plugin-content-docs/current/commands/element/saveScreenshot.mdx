# saveScreenshot

## Обзор {/* #overview */}

Используйте команду `saveScreenshot`, чтобы сохранить скриншот элемента в png-файл.

## Использование {/* #usage */}

```javascript
await browser.$(selector).saveScreenshot(filepath);
```

## Параметры команды {/* #parameters */}

<table>
<thead>
<tr><td>**Имя**</td><td>**Тип**</td><td>**Описание**</td></tr>
</thead>
<tbody>
<tr><td>filepath</td><td>String</td><td>Путь к скриншоту относительно каталога выполнения (расширение .png — обязательно).</td></tr>

</tbody>
</table>

## Примеры использования {/* #examples */}

Сохраним изображение бейджа, а не всей видимой области страницы. Каталог назначения должен существовать.

```javascript testplane=element-save-screenshot fixture=element-screenshot
const badge = await browser.$("#badge");
await badge.saveScreenshot(`./artifacts/badge-${browser.sessionId}.png`);
```
