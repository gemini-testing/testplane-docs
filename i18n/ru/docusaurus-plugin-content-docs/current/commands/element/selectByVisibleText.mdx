# selectByVisibleText

## Обзор {/* #overview */}

Используйте команду `selectByVisibleText`, чтобы выбрать опцию с заданным отображаемым текстом.

## Использование {/* #usage */}

```javascript
await browser.$(selector).selectByVisibleText(text);
```

## Примеры использования {/* #examples */}

**example.html**

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option value="someValue5">seis</option>
</select>
```

**selectByVisibleText.js**

```javascript testplane=element-select-by-visible-text-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the selectByVisibleText command", async ({ browser }) => {
    const selectBox = await browser.$("#selectbox");
    let text = await selectBox.$("option:checked").getText();
    console.log(text); // выведет: "uno"
    assert.equal(text, "uno");

    await selectBox.selectByVisibleText("cuatro");
    text = await selectBox.$("option:checked").getText();
    console.log(text); // выведет: "cuatro"
    assert.equal(text, "cuatro");
});
```
