# selectByAttribute

## Обзор {/* #overview */}

Используйте команду `selectByAttribute`, чтобы выбрать опцию с определенным значением.

## Использование {/* #usage */}

```javascript
await browser.$(selector).selectByAttribute(attribute, value);
```

## Примеры использования {/* #examples */}

**example.html**

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option name="someName5" value="someValue5">seis</option>
</select>
```

**selectByAttribute.js**

```javascript testplane=element-select-by-attribute-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the selectByAttribute command", async ({ browser }) => {
    const selectBox = await browser.$("#selectbox");
    let value = await selectBox.getValue();
    console.log(value); // выведет: "someValue0"
    assert.equal(value, "someValue0");

    await selectBox.selectByAttribute("value", "someValue3");
    value = await selectBox.getValue();
    console.log(value); // выведет: "someValue3"
    assert.equal(value, "someValue3");

    await selectBox.selectByAttribute("name", "someName5");
    value = await selectBox.getValue();
    console.log(value); // выведет: "someValue5"
    assert.equal(value, "someValue5");
});
```
