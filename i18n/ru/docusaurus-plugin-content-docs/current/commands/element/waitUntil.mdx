# waitUntil

## Обзор {/* #overview */}

Используйте команду `waitUntil`, чтобы дождаться соблюдения определенного условия на странице в браузере.

## Использование {/* #usage */}

```javascript
await browser.$(selector).waitUntil(condition, { timeout, timeoutMsg, interval });
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div id="someText">I am some text</div>
<script>
    setTimeout(() => {
        document.getElementById("someText").innerHTML = "I am now different";
    }, 1000);
</script>
```

```javascript testplane=element-wait-until fixture=element-html
const assert = require("node:assert/strict");

const text = await browser.$("#someText");
await text.waitUntil(
    async function () {
        return (await this.getText()) === "I am now different";
    },
    { timeout: 5000, timeoutMsg: "expected text to change within 5s" },
);
assert.equal(await text.getText(), "I am now different");
```
