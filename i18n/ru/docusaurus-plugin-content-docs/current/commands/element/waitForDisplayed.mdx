# waitForDisplayed

## Обзор {/* #overview */}

Используйте команду `waitForDisplayed`, чтобы подождать, пока элемент в течение указанного количества миллисекунд не станет отображаемым или не отображаемым.

<Admonition type="warning">
    В отличие от других команд элемента, testplane не будет дожидаться существования элемента, чтобы
    выполнить эту команду.
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).waitForDisplayed({ timeout, reverse, timeoutMsg, interval });
```

## Параметры команды {/* #parameters */}

</tbody>

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<button
    id="toggle"
    onclick="setTimeout(() => document.querySelector('#message').toggleAttribute('hidden'), 100)"
>
    Toggle message
</button>
<div id="message" hidden>Hello World!</div>
```

**waitForDisplayed.js**

```javascript testplane=element-wait-for-displayed fixture=element-html
const assert = require("node:assert/strict");

it("should detect when element is visible", async ({ browser }) => {
    const message = await browser.$("#message");
    const toggle = await browser.$("#toggle");

    await toggle.click();
    await message.waitForDisplayed({ timeout: 3000 });
    assert.equal(await message.isDisplayed(), true);
});

it("should detect when element is no longer visible", async ({ browser }) => {
    const message = await browser.$("#message");
    const toggle = await browser.$("#toggle");

    await toggle.click();
    await message.waitForDisplayed({ timeout: 3000 });

    await toggle.click();
    await message.waitForDisplayed({ reverse: true });
    assert.equal(await message.isDisplayed(), false);
});
```
