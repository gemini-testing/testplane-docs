# addValue

## Обзор {/* #overview */}

Используйте команду `addValue`, чтобы добавить значение в элемент типа `<input>` или `<textarea>`.

## Использование {/* #usage */}

```javascript
await browser.$(selector).addValue(value);
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<input class="input" />
```

```javascript testplane=element-add-value fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the addValue command", async ({ browser }) => {
    const input = await browser.$(".input");
    await input.addValue("test");
    await input.addValue(123);

    const value = await input.getValue(); // "test123"
    assert.equal(value, "test123");
});
```
