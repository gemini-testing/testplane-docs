# getSize

## Обзор {/* #overview */}

Используйте команду `getSize`, чтобы получить ширину и высоту DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getSize(prop);
```

## Параметры команды {/* #parameters */}

<table>
<thead>
<tr><td>**Имя**</td><td>**Тип**</td><td>**Описание**</td></tr>
</thead>
<tbody>
<tr><td>prop</td><td>String</td><td>Необязательный параметр. Размер, который нужно получить: "width" или "height". Если параметр не указан, то команда вернет объект вида _\{ width, height }_.</td></tr>

</tbody>
</table>

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div id="logo" style="width: 32px; height: 32px">Logo</div>
```

```javascript testplane=element-get-size fixture=element-html
const assert = require("node:assert/strict");

const logo = await browser.$("#logo");
assert.deepEqual(await logo.getSize(), { width: 32, height: 32 });
assert.equal(await logo.getSize("width"), 32);
assert.equal(await logo.getSize("height"), 32);
```
