# $$

## Обзор {/* #overview */}

Используйте команду `$$` вместо [findElements][find-elements] как более краткую команду, чтобы получить несколько элементов на странице в области видимости элемента. Эта команда похожа на команду [browser.$$()](../../browser/_dollardollar), и отличается только тем, что поиск элементов будет осуществляться среди потомков _(children)_ текущего элемента.

<Admonition type="info">
    Подробнее о том, как выбрать определенные элементы, смотрите в рецепте «[Как использовать
    селекторы][how-to-use-selectors]».
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).$$(subSelector);
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<ul id="menu">
    <li>
        <a href="/">Home</a>
    </li>
    <li>
        <a href="/">Developer Guide</a>
    </li>
    <li>
        <a href="/">API</a>
    </li>
    <li>
        <a href="/">Contribute</a>
    </li>
</ul>
```

```javascript testplane=element-find-all-css fixture=element-html
const assert = require("node:assert/strict");

const menu = await browser.$("#menu");
const items = await menu.$$("li");
assert.equal(await items[2].$("a").getText(), "API");
```

В функции-селекторе `this` указывает на текущий `HTMLUListElement`. Используйте обычную функцию, а не стрелочную. В TypeScript можно указать тип контекста: `function (this: HTMLUListElement)`.

```javascript testplane=element-find-all-function fixture=element-html
const assert = require("node:assert/strict");

const menu = await browser.$("#menu");
const items = await menu.$$(function () {
    return this.querySelectorAll("li");
});
assert.equal(await items[2].$("a").getText(), "API");
```
