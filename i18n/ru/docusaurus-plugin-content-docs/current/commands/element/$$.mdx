# $$

## Обзор {/* #overview */}

Используйте команду `$$` вместо [findElements][find-elements] как более краткую команду, чтобы получить несколько элементов на странице в области видимости элемента. Эта команда похожа на команду [browser.$$()](../../browser/_dollardollar), и отличается только тем, что поиск элементов будет осуществляться среди потомков _(children)_ текущего элемента.

<Admonition type="info">
    Подробнее о том, как выбрать определенные элементы, смотрите в рецепте «[Как использовать
    селекторы][how-to-use-selectors]».
</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).$$(subSelector);
```

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<ul id="menu">
    <li>
        <a href="/">Home</a>
    </li>
    <li>
        <a href="/">Developer Guide</a>
    </li>
    <li>
        <a href="/">API</a>
    </li>
    <li>
        <a href="/">Contribute</a>
    </li>
</ul>
```

**$$.js**

```javascript testplane=element-find-all-css-ru fixture=element-html
const assert = require("node:assert/strict");

it("should get text of a menu link", async ({ browser }) => {
    const menu = await browser.$("#menu");
    const items = await menu.$$("li");
    const link = await items[2].$("a");

    const text = await link.getText();
    console.log(text); // выведет: "API"
    assert.equal(text, "API");
});
```

```javascript testplane=element-find-all-function-ru fixture=element-html
const assert = require("node:assert/strict");

it("should get text of a menu link - JS Function", async ({ browser }) => {
    const menu = await browser.$("#menu");
    const items = await menu.$$(function () {
        // Используйте обычную функцию: у стрелочной функции this не указывает на элемент.
        // Здесь this — HTMLUListElement, DOM-элемент:
        // https://developer.mozilla.org/en-US/docs/Web/API/Element
        //
        // В TypeScript тип this можно указать в объявлении функции:
        // function (this: HTMLUListElement) { ... }
        return this.querySelectorAll("li"); // NodeListOf<HTMLLIElement>
    });
    const link = await items[2].$("a");

    const text = await link.getText();
    console.log(text); // выведет: "API"
    assert.equal(text, "API");
});
```
