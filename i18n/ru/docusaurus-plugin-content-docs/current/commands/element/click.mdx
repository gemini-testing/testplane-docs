# click

## Обзор {/* #overview */}

Используйте команду `click`, чтобы кликнуть по элементу.

<Admonition type="warning">
Если у вас есть элементы с фиксированным положением (например, фиксированный _header_ или _footer)_, которые закрывают выбранный элемент после подскролла к нему, то клик будет произведен в заданных координатах, но будет получен вашим фиксированным (накладывающимся) элементом. В этих случаях выдается следующая ошибка:

_Element is not clickable at point (x, x). Other element would receive the click: ..._

Чтобы обойти это, попробуйте найти накладывающийся элемент и удалить его с помощью команды [execute][execute], чтобы он не мешал клику. Вы также можете попробовать проскроллить элемент самостоятельно, используя скролл со смещением, соответствующим вашему сценарию.

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).click({ button, x, y, skipRelease });
```

## Параметры команды {/* #parameters */}

## Примеры использования {/* #examples */}

### Пример 1

```html testplane-html=element-html
<button id="myButton" onclick="document.querySelector('#someText').textContent = 'I was clicked'">
    Click me
</button>
<div id="someText">I was not clicked</div>
```

```javascript testplane=element-click fixture=element-html
const assert = require("node:assert/strict");

await browser.$("#myButton").click();
assert.equal(await browser.$("#someText").getText(), "I was clicked");
```

Чтобы перейти по каждой ссылке в меню с якорями на этой странице:

```html testplane-html=element-links
<nav id="menu"><a href="#guide">Guide</a> <a href="#api">API</a></nav>
<h2 id="guide">Guide</h2>
<h2 id="api">API</h2>
```

```javascript testplane=element-click-links fixture=element-links
const assert = require("node:assert/strict");

const links = await browser.$$("#menu a");
assert.equal(links.length, 2);
for (const link of links) {
    const href = await link.getAttribute("href");
    await link.click();
    assert.equal(new URL(await browser.getUrl()).hash, href);
}
```

### Пример 2

```html testplane-html=element-click-offset
<button id="myButton" style="width: 120px">Click me</button>
```

Кликнем на 30 пикселей правее центра кнопки:

```javascript testplane=element-click-offset fixture=element-click-offset
await browser.$("#myButton").click({ x: 30 });
```

### Пример 3

```html testplane-html=element-click-right
<button id="myButton" style="width: 120px; height: 100px">Click me</button>
```

Для правого клика можно указать имя или номер кнопки. Последний вызов пропускает `releaseActions`:

```javascript testplane=element-click-right fixture=element-click-right
const button = await browser.$("#myButton");
await button.click({ button: "right" });
await button.click({ button: 2, x: 30, y: 40 });
await button.click({ button: 2, x: 30, y: 40, skipRelease: true });
```
