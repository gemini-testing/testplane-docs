# selectByIndex

## Обзор {/* #overview */}

Используйте команду `selectByIndex`, чтобы выбрать опцию с определенным значением.

## Использование {/* #usage */}

```javascript
await browser.$(selector).selectByIndex(index);
```

## Примеры использования {/* #examples */}

**example.html**

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option value="someValue5">seis</option>
</select>
```

**selectByIndex.js**

```javascript testplane=element-select-by-index-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the selectByIndex command", async ({ browser }) => {
    const selectBox = await browser.$("#selectbox");
    let value = await selectBox.getValue();
    console.log(value); // выведет: "someValue0"
    assert.equal(value, "someValue0");

    await selectBox.selectByIndex(4);
    value = await selectBox.getValue();
    console.log(value); // выведет: "someValue4"
    assert.equal(value, "someValue4");
});
```
