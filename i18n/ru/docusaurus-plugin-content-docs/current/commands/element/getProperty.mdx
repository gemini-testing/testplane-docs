# getProperty

## Обзор {/* #overview */}

Используйте команду `getProperty`, чтобы получить свойство элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getProperty(property);
```

## Примеры использования {/* #examples */}

```javascript testplane=element-get-property-ru fixture=element-document
const assert = require("node:assert/strict");

it("should demonstrate the getProperty command", async ({ browser }) => {
    const elem = await browser.$("body");
    const tag = await elem.getProperty("tagName");
    console.log(tag); // выведет: "BODY"
    assert.equal(tag, "BODY");
});
```
