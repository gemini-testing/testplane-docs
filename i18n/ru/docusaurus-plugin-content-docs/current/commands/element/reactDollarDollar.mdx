# react$$

## Обзор {/* #overview */}

Используйте команду `react$$`, чтобы найти на странице множество React-компонентов по их настоящему имени, одновременно фильтруя их по props'ам и состоянию.

<Admonition type="warning">
Начинайте поиск с DOM-элемента, отрисованного React, а не с внешнего контейнера монтирования. Пример ниже проверяется на React 18.2.

Читайте больше о React-селекторах в рецепте «[Как использовать селекторы][how-to-use-selectors]».

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).react$$(reactComponentSelector, { props, state });
```

## Примеры использования {/* #examples */}

Найдём только клавиши калькулятора, у которых проп `orange` равен `true`.

```javascript testplane=element-react-dollar-dollar fixture=element-calculator
const assert = require("node:assert/strict");

const calculator = await browser.$(".calculator");
const buttons = await calculator.react$$("Button", { props: { orange: true } });
const labels = await buttons.map(button => button.getText());
assert.deepEqual(labels, ["÷", "x", "-", "+", "="]);
```
