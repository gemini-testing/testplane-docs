# getTagName

## Обзор {/* #overview */}

Используйте команду `getTagName`, чтобы получить имя тега DOM-элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getTagName();
```

## Примеры использования {/* #examples */}

**index.html**

```html testplane-html=element-html
<div id="elem">Lorem ipsum</div>
```

**getTagName.js**

```javascript testplane=element-get-tag-name-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getTagName command", async ({ browser }) => {
    const elem = await browser.$("#elem");
    const tagName = await elem.getTagName();
    console.log(tagName); // выведет: "div"
    assert.equal(tagName, "div");
});
```
