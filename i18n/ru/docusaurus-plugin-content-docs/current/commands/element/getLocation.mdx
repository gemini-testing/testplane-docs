# getLocation

## Обзор {/* #overview */}

Используйте команду `getLocation`, чтобы определить местоположение элемента на странице.

Точка `(0, 0)` относится к верхнему левому углу страницы.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getLocation(prop);
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div id="logo" style="position: absolute; left: 150px; top: 20px">Logo</div>
```

```javascript testplane=element-get-location fixture=element-html
const assert = require("node:assert/strict");

const logo = await browser.$("#logo");
assert.deepEqual(await logo.getLocation(), { x: 150, y: 20 });
assert.equal(await logo.getLocation("x"), 150);
assert.equal(await logo.getLocation("y"), 20);
```
