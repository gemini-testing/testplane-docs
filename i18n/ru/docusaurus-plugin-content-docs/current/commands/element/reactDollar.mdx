# react$

## Обзор {/* #overview */}

Используйте команду `react$`, чтобы найти на странице React-компоненты по их настоящему имени, одновременно фильтруя их по props'ам и состоянию.

<Admonition type="warning">
Начинайте поиск с DOM-элемента, отрисованного React, а не с внешнего контейнера монтирования. Пример ниже проверяется на React 18.2.

Читайте больше о React-селекторах в рецепте «[Как использовать селекторы][how-to-use-selectors]».

</Admonition>

## Использование {/* #usage */}

```javascript
await browser.$(selector).react$(reactComponentSelector, { props, state });
```

## Примеры использования {/* #examples */}

Найдём клавиши калькулятора по имени компонента `Button` и значению его пропа `name`.

```javascript testplane=element-react-dollar fixture=element-calculator
const assert = require("node:assert/strict");

const calculator = await browser.$(".calculator");
for (const name of ["7", "x", "6", "="]) {
    await calculator.react$("Button", { props: { name } }).click();
}
assert.equal(await calculator.$(".component-display").getText(), "42");
```
