# shadow$$

## Обзор {/* #overview */}

Используйте команду `shadow$$`, чтобы получить доступ к элементам внутри [ShadowRoot][shadow-root] данного элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).shadow$$(shadowSelector);
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<div class="input">
    <template shadowrootmode="open">
        <input id="innerEl" value="test123" />
        <input value="second" />
    </template>
</div>
```

```javascript testplane=element-shadow-dollar-dollar-ru fixture=element-html
const assert = require("node:assert/strict");

it("should return elements inside a ShadowRoot", async ({ browser }) => {
    const host = await browser.$(".input");
    const inputs = await host.shadow$$("input");
    assert.equal(inputs.length, 2);

    const firstValue = await inputs[0].getValue();
    console.log(firstValue); // выведет: "test123"
    assert.equal(firstValue, "test123");

    const secondValue = await inputs[1].getValue();
    console.log(secondValue); // выведет: "second"
    assert.equal(secondValue, "second");
});
```
