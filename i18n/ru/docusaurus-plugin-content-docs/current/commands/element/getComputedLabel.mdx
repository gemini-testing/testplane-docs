# getComputedLabel

## Обзор {/* #overview */}

Используйте команду `getComputedLabel`, чтобы получить вычисленную [WAI-ARIA][wai-aria] метку элемента.

## Использование {/* #usage */}

```javascript
await browser.$(selector).getComputedLabel();
```

## Примеры использования {/* #examples */}

```html testplane-html=element-html
<select name="q" aria-label="Search">
    <option>All</option>
</select>
```

```javascript testplane=element-get-computed-label-ru fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getComputedLabel command", async ({ browser }) => {
    const elem = await browser.$('[name="q"]');
    const label = await elem.getComputedLabel();
    console.log(label); // выведет: "Search"
    assert.equal(label, "Search");
});
```

[wai-aria]: https://ru.wikipedia.org/wiki/WAI-ARIA
