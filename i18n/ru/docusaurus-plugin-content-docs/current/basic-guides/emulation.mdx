# Эмуляция

## Производительность CPU

<Admonition type="warning">

Данная функция работает только браузерами, поддерживающими _Chrome DevTools Protocol (CDP)_.

</Admonition>

Скорость работы процессора на мобильных устройствах сильно уступает скорости на компьютерах. Поэтому для эмуляции скорости CPU в Testplane существует метод [emulateCPUThrottling][emulate-cpu-throttling].

### Пример: замедляем скорость процессора в 8 раз

В примерах ниже по пути `/navigation` открывается страница с заголовком «Navigation». Чтобы запустить тесты на своем сайте, укажите его адрес в `baseUrl`, а в тестах подставьте путь страницы и ее заголовок.

```javascript testplane=guide-cpu-emulation-ru fixture=guides-page transport=cdp
it("открывает страницу при восьмикратном замедлении процессора", async function ({ browser }) {
    // Получаем экземпляр Puppeteer
    const puppeteer = await browser.getPuppeteer();

    // Получаем первую открытую страницу (считаем, что она активная в данный момент)
    const [page] = await puppeteer.pages();

    // Замедляем скорость процессора в 8 раз
    await page.emulateCPUThrottling(8);

    try {
        await browser.url("/navigation");
        await expect(browser.$("h1")).toHaveText("Navigation");
    } finally {
        await page.emulateCPUThrottling(1);
    }
});
```

## Пропускная способность сети

<Admonition type="warning">

Данная функция работает только браузерами, поддерживающими _Chrome DevTools Protocol (CDP)_.

</Admonition>

Огромное количество пользователей пользуются сервисами с мобильных устройств, на которых скорость интернета бывает довольно медленной или совсем пропадает на время. В _webdriverio_ мы можем ограничить пропускную способность сети с помощью метода [throttleNetwork][throttle] и таким образом протестировать поведение сайта в сетях с разной пропускной способностью.

Помимо индивидуальных настроек метод [throttleNetwork][throttle] поддерживает следующие готовые пресеты:

-   offline | online
-   GPRS
-   Regular2G | Good2G
-   Regular3G | Good3G
-   Regular4G
-   DSL
-   WiFi

### Пример 1: эмуляция 2G-соединения

Ограничим скорость сети в обычной вкладке Chrome и убедимся, что страница по-прежнему доступна:

```javascript testplane=guide-network-preset-ru fixture=guides-page transport=cdp
it("открывает страницу при 2G-соединении", async function ({ browser }) {
    // Имитируем 2G-соединение
    await browser.throttleNetwork("Good2G");

    try {
        await browser.url("/navigation");
        await expect(browser.$("h1")).toHaveText("Navigation");
    } finally {
        await browser.throttleNetwork("online");
    }
});
```

### Пример 2: эмуляция сети с заданными характеристиками

Также мы можем сэмулировать соединение с конкретными характеристиками:

```javascript testplane=guide-network-custom-ru fixture=guides-page transport=cdp
it("открывает страницу с заданными параметрами сети", async function ({ browser }) {
    // Имитируем соединение в сети с заданными характеристиками
    await browser.throttleNetwork({
        offline: false, // false — сеть остается доступной
        downloadThroughput: (10 * 1024) / 8, // максимальная пропускная способность загрузки (байт/с)
        uploadThroughput: (10 * 1024) / 8, // максимальная пропускная способность отправки (байт/с)
        latency: 10, // минимальная задержка в миллисекундах от отправки запроса до получения заголовков ответа
    });

    try {
        await browser.url("/navigation");
        await expect(browser.$("h1")).toHaveText("Navigation");
    } finally {
        await browser.throttleNetwork("online");
    }
});
```

[emulate-cpu-throttling]: https://pptr.dev/api/puppeteer.page.emulatecputhrottling
[throttle]: https://webdriver.io/docs/api/browser/throttleNetwork
