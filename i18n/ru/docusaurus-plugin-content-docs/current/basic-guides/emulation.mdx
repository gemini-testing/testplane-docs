# Эмуляция

## Производительность CPU

<Admonition type="warning">

Данная функция работает только браузерами, поддерживающими _Chrome DevTools Protocol (CDP)_.

</Admonition>

Скорость работы процессора на мобильных устройствах сильно уступает скорости на компьютерах. Поэтому для эмуляции скорости CPU в Testplane существует метод [emulateCPUThrottling][emulate-cpu-throttling].

### Пример: замедляем скорость процессора в 8 раз

```javascript testplane=guide-cpu-emulation fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const [page] = await (await browser.getPuppeteer()).pages();
await page.emulateCPUThrottling(8);
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
await page.emulateCPUThrottling(1);
```

## Пропускная способность сети

<Admonition type="warning">

Данная функция работает только браузерами, поддерживающими _Chrome DevTools Protocol (CDP)_.

</Admonition>

Огромное количество пользователей пользуются сервисами с мобильных устройств, на которых скорость интернета бывает довольно медленной или совсем пропадает на время. В _webdriverio_ мы можем ограничить пропускную способность сети с помощью метода [throttleNetwork][throttle] и таким образом протестировать поведение сайта в сетях с разной пропускной способностью.

Помимо индивидуальных настроек метод [throttleNetwork][throttle] поддерживает следующие готовые пресеты:

-   offline | online
-   GPRS
-   Regular2G | Good2G
-   Regular3G | Good3G
-   Regular4G
-   DSL
-   WiFi

### Пример 1: эмуляция 2G-соединения

Ограничим скорость сети в обычной вкладке Chrome и убедимся, что страница по-прежнему доступна:

```javascript testplane=guide-network-preset fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

await browser.throttleNetwork("Good2G");
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
```

### Пример 2: эмуляция сети с заданными характеристиками

Также мы можем сэмулировать соединение с конкретными характеристиками:

```javascript testplane=guide-network-custom fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

await browser.throttleNetwork({
    offline: false,
    downloadThroughput: (10 * 1024) / 8,
    uploadThroughput: (10 * 1024) / 8,
    latency: 10,
});
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
```
