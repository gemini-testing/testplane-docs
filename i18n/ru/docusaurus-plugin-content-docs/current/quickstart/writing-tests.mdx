# Написание тестов

В примерах используются две локальные страницы: [поиск по документации](https://github.com/gemini-testing/testplane-docs/blob/master/test/doc-examples/fixtures/site/quickstart/docs.html) и [книжный магазин](https://github.com/gemini-testing/testplane-docs/blob/master/test/doc-examples/fixtures/site/quickstart/bookstore.html). Раздайте эти файлы по пути `/fixtures/quickstart/` на своем `baseUrl` или подставьте URL и селекторы вашего приложения.

## Структура теста

```typescript testplane=quickstart-structure-ru fixture=quickstart-page
describe("Название группы тестов", () => {
    it("открывает главную страницу документации", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");
        await expect(browser.$("h1")).toHaveText("Fast testplane docs");
    });
});
```

-   `describe` группирует связанные тесты
-   `it` описывает конкретный тестовый сценарий
-   `browser` — объект браузера для взаимодействия со страницей

После установки Testplane можно ознакомиться с примером теста в файле `testplane-tests/example.testplane.ts`.

<details>

    <summary>Пример теста</summary>

    ```typescript title="example.testplane.ts" testplane=quickstart-search fixture=quickstart-testing-library
    describe("test examples", () => {
        it("docs search test", async ({ browser }) => {
            await browser.openAndWait("/fixtures/quickstart/docs.html");

            // Find by tag name
            const navBar = await browser.$("nav");

            // Find by aria-label
            await navBar.$("aria/Search").click();

            // Find by placeholder
            const fileSearchInput = await browser.findByPlaceholderText("Search docs");
            await fileSearchInput.waitForDisplayed();
            await fileSearchInput.setValue("config");

            // Find by id
            const fileSearchResults = await browser.$("#docsearch-list");

            // Find by role
            const fileSearchResultsItems = await fileSearchResults.findAllByRole("option");

            expect(fileSearchResultsItems.length).toBe(2);
            await expect(fileSearchResultsItems[0]).toHaveText("Browser configuration");
        });
    });
    ```

</details>

## Базовый синтаксис

### Навигация

Для перемещения по страницам используйте метод [`browser.url()`](../commands/browser/url.mdx):

```typescript testplane=quickstart-navigation fixture=quickstart-page
await browser.url("/fixtures/quickstart/docs.html");
await expect(browser).toHaveTitle("Fast testplane docs");
```

Для перехода на страницу можно также использовать команду [`browser.openAndWait()`](../commands/browser/openAndWait.mdx), которая поддерживает больше настроек, связанных с загрузкой статики на странице.

### Селекторы

Testplane поддерживает различные стратегии поиска элементов: CSS-селекторы (самые распространенные), текстовые селекторы (по содержимому), XPath для сложных запросов. Метод [`$()`](../commands/browser/$.mdx) возвращает первый найденный элемент, а [`$$()`](../commands/browser/$$.mdx) — массив всех подходящих.

Также есть поддержка селекторов Testing Library, это позволяет писать более читаемые тесты, ориентированные на пользовательское поведение. При инициализации через `npm init testplane` она уже включена. Если вы создавали проект иначе, ее можно [установить вручную](../guides/how-to-add-testing-library.mdx).

```typescript testplane=quickstart-selectors-ru fixture=quickstart-testing-library
describe("Примеры селекторов", () => {
    it("Первый найденный элемент", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/bookstore.html");

        const heading = await browser.$("h1");
        await expect(heading).toHaveText("Bookstore");
        const input = await browser.$('[data-testid="search-input"]');
        const inputTL = await browser.findByTestId("search-input");
        expect(inputTL.elementId).toBe(input.elementId);
    });

    it("Поиск нескольких элементов", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        const links = await browser.$$("a");
        expect(links.length).toBeGreaterThan(0);
    });
});
```

#### Типы селекторов

```typescript testplane=quickstart-selector-types-ru fixture=quickstart-testing-library
describe("Типы селекторов", () => {
    it("CSS-селекторы", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/bookstore.html");

        // data-атрибуты
        const input = await browser.$('[data-testid="search-input"]');
        const inputTL = await browser.findByTestId("search-input");
        expect(inputTL.elementId).toBe(input.elementId);

        // CSS-классы и теги
        const navbar = await browser.$(".navbar");
        const heading = await browser.$("h1");
        await expect(navbar).toBeDisplayed();
        await expect(heading).toHaveText("Bookstore");
    });

    it("Текстовые селекторы", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Поиск по точному тексту
        const match = await browser.$("=Docs");

        // Поиск по частичному совпадению
        const partial = await browser.$("*=Doc");
        await expect(match).toHaveText("Docs");
        expect(partial.elementId).toBe(match.elementId);
    });

    it("XPath", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Поиск по тексту внутри элемента
        const link = await browser.$('//a[text()="Docs"]');
        await expect(link).toBeDisplayed();
    });
});
```

Подробнее про селекторы читайте в [этой статье](../basic-guides/selectors.mdx).

### Взаимодействие с элементами

#### Клик

```typescript testplane=quickstart-click-ru fixture=quickstart-page
const assert = require("node:assert/strict");

describe("Клик", () => {
    it("Клик и двойной клик", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Клик по кнопке поиска
        const searchButton = await browser.$("button.DocSearch");
        await searchButton.waitForClickable({ timeout: 5000 });
        await searchButton.click();
        const modal = await browser.$(".DocSearch-Modal");
        await modal.waitForDisplayed({ timeout: 5000 });

        const result = await modal.$('[role="option"]');
        await result.doubleClick();
        assert.strictEqual(await result.getAttribute("aria-selected"), "true");
    });
});
```

Подробнее см. в статьях о [`click()`](../commands/element/click.mdx) и [`doubleClick()`](../commands/element/doubleClick.mdx).

#### Ввод текста

```typescript testplane=quickstart-input-ru fixture=quickstart-page
const assert = require("node:assert/strict");

describe("Ввод текста", () => {
    it("Ввод текста в поле поиска", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Клик по кнопке поиска
        const searchButton = await browser.$("button.DocSearch");
        await searchButton.waitForClickable({ timeout: 5000 });
        await searchButton.click();

        // Ввод текста в поле поиска
        const searchInput = await browser.$("input.DocSearch-Input");
        await searchInput.waitForDisplayed({ timeout: 5000 });
        await searchInput.setValue("browser");

        // Проверка
        const inputValue = await searchInput.getValue();
        assert.strictEqual(inputValue, "browser");
    });
});
```

Подробнее см. в статье о [`setValue()`](../commands/element/setValue.mdx).

#### Взаимодействие с формами

```typescript testplane=quickstart-forms-ru fixture=quickstart-page
const assert = require("node:assert/strict");

describe("Взаимодействие с формами", () => {
    it("Чекбокс", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/bookstore.html#login");

        const checkbox = await browser.$('[data-testid="remember-checkbox"]');
        await checkbox.waitForDisplayed({ timeout: 5000 });

        // Проверка начального состояния
        let isSelected = await checkbox.isSelected();
        assert.strictEqual(isSelected, false);

        // Выбор
        await checkbox.click();
        isSelected = await checkbox.isSelected();
        assert.strictEqual(isSelected, true);

        // Снятие выбора
        await checkbox.click();
        isSelected = await checkbox.isSelected();
        assert.strictEqual(isSelected, false);
    });

    it("Выпадающий список", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/bookstore.html");

        const dropdown = await browser.$('[data-testid="sort-select"]');
        await dropdown.waitForDisplayed({ timeout: 5000 });

        // Выбор опции по видимому тексту
        await dropdown.selectByVisibleText("Highest Rated");

        // Проверка выбранного значения
        let selectedValue = await dropdown.getValue();
        assert.strictEqual(selectedValue, "rating");

        // Проверка текста выбранной опции
        let selectedText = await dropdown.$("option:checked").getText();
        assert.strictEqual(selectedText, "Highest Rated");
    });
});
```

Подробнее см. в статьях о методах [`isSelected()`](../commands/element/isSelected.mdx) и [`selectByVisibleText()`](../commands/element/selectByVisibleText.mdx).

### Assertions

Assertions — это проверки, которые сравнивают фактический результат с ожидаемым.

```typescript testplane=quickstart-assertions-ru fixture=quickstart-page
describe("Assertions", () => {
    it("Проверка элементов", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        const heading = await browser.$("h1");

        // Проверка существования и видимости
        await expect(heading).toExist();
        await expect(heading).toBeDisplayed();

        // Проверка текста
        await expect(heading).toHaveTextContaining("testplane");

        // Проверка атрибутов
        await expect(heading).toHaveAttribute("class", "title");
    });
});
```

Подробнее см. в [документации по assertions](../commands/expect/overview.mdx).

### Хуки

Хуки позволяют подготовить окружение перед тестами и очистить его после выполнения.

```typescript testplane=quickstart-hooks-ru fixture=quickstart-page
describe("Работа с хуками", () => {
    beforeEach(async ({ browser }) => {
        // Выполняется перед каждым тестом
        await browser.url("/fixtures/quickstart/docs.html");
        await browser.setCookies({ name: "visit", value: "1" });
    });

    afterEach(async ({ browser }) => {
        // Выполняется после каждого теста
        await browser.deleteAllCookies();
        expect(await browser.getCookies("visit")).toHaveLength(0);
    });

    it("Первый тест", async ({ browser }) => {
        // Страница уже открыта благодаря beforeEach
        const title = await browser.getTitle();
        expect(title).toContain("Fast");
    });

    it("Второй тест", async ({ browser }) => {
        // Страница снова открыта, cookies очищены
        const heading = await browser.$("h1");
        await expect(heading).toExist();
    });
});
```

Подробнее о хуках см. в [документации](../basic-guides/setup-and-teardown.mdx).

### Ожидания

Явные ожидания (например, [`waitForDisplayed()`](../commands/element/waitForDisplayed.mdx) и [`waitUntil()`](../commands/element/waitUntil.mdx)) необходимы для работы с динамическим контентом:

```typescript testplane=quickstart-waits-ru fixture=quickstart-page
describe("Ожидание", () => {
    it("Ожидание элементов", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        const button = await browser.$("button*=Get");

        // Ожидание появления
        await button.waitForDisplayed({ timeout: 5000 });
    });

    it("Кастомное ожидание", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        const heading = await browser.$("h1");

        // Ожидание появления текста заголовка
        await heading.waitUntil(
            async function () {
                const text = await this.getText();
                return text.length > 0;
            },
            {
                timeout: 5000,
                timeoutMsg: "Текст заголовка не появился",
            },
        );
    });
});
```

## Визуальное тестирование

Testplane позволяет делать скриншоты элементов и сравнивать их с эталонными изображениями с помощью команды [`assertView()`](../commands/browser/assertView.mdx).

Создайте и проверьте эталонные скриншоты с помощью `testplane --update-refs`. Обычный прогон без эталона завершается ошибкой. При последующих запусках Testplane сравнивает новые скриншоты с эталонами и сообщает о различиях. Если различий нет, тест проходит. Если есть различия, тест падает, а diff-изображение сохраняется для анализа.

```typescript testplane=quickstart-visual-ru fixture=quickstart-visual
describe("Визуальная проверка", () => {
    it("Логотип", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Ожидание появления элемента
        const brand = await browser.$(".navbar__brand");
        await brand.waitForDisplayed({ timeout: 10000 });

        // Скриншот элемента
        await browser.assertView("default", ".navbar__brand");
    });
});
```

## Выполнение JavaScript

Метод [`execute()`](../commands/browser/execute.mdx) выполняет JavaScript-код в контексте страницы:

```typescript testplane=quickstart-execute-ru fixture=quickstart-page
describe("Выполнение JavaScript", () => {
    it("Пример", async ({ browser }) => {
        await browser.url("/fixtures/quickstart/docs.html");

        // Работа с localStorage
        await browser.execute(() => {
            localStorage.setItem("theme", "dark");
        });

        const theme = await browser.execute(() => {
            return localStorage.getItem("theme");
        });
        expect(theme).toBe("dark");

        // Передача параметров
        const sum = await browser.execute((a, b) => a + b, 5, 10);
        expect(sum).toBe(15);
    });
});
```
