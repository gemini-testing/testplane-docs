# Тестирование доступности

## Обзор {/* #overview */}

<Admonition type="warning">
Данный рецепт работает только при использовании _Chrome DevTools Protocol (CDP)_.

Читайте подробности в разделе «[Как использовать CDP в Testplane][how-to-use-cdp]»

</Admonition>

[Accessibility tree][accessibility-tree] — это дерево доступности, которое содержит иерархическую структуру доступных объектов. В отличие от DOM-дерева, которое предназначено для браузеров, accessibility-дерево предназначено для [скрин-ридеров][screen-reader] и других инструментов, помогающих взаимодействовать с сайтами людям с ограниченными возможностями.

Для получения такого дерева в _puppeteer_ есть специальный [класс Accessibility][puppeteer-accessibility].

## Пример {/* #example */}

Снимем дерево доступности локального портала. Проверим роль и доступное имя страницы, а затем найдем ссылки, которые может озвучить скрин-ридер.

```javascript testplane=guide-accessibility-tree-ru fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

it("читает дерево доступности портала", async ({ browser }) => {
    // Получаем подключение Puppeteer для текущей сессии Testplane.
    const puppeteer = await browser.getPuppeteer();

    // В этом тесте открыта одна вкладка, поэтому первая страница — активная.
    const [page] = await puppeteer.pages();
    await browser.url("/fixtures/guides/accessibility.html");

    // Выводим дерево доступности, а не DOM: у его узлов есть роли и доступные имена.
    const snapshot = await page.accessibility.snapshot();
    console.log(JSON.stringify(snapshot, null, 2));

    assert.equal(snapshot.role, "RootWebArea");
    assert.equal(snapshot.name, "Team portal");

    // Выбираем ссылки по роли: в дереве могут быть и текстовые узлы.
    const links = snapshot.children.filter(node => node.role === "link");
    const names = links.map(link => link.name);
    assert.deepEqual(names, ["Sign in", "Inbox", "Drive", "Finance", "Help"]);
});
```

## Accessibility-дерево {/* #accessibility_tree */}

Ниже показаны корень и ссылки из полученного дерева. Промежуточные текстовые узлы опущены:

```json
{
    "role": "RootWebArea",
    "name": "Team portal",
    "children": [
        {
            "role": "link",
            "name": "Sign in"
        },
        {
            "role": "link",
            "name": "Inbox"
        },
        {
            "role": "link",
            "name": "Drive"
        },
        {
            "role": "link",
            "name": "Finance"
        },
        {
            "role": "link",
            "name": "Help"
        }
    ]
}
```

Используя полученное дерево мы можем проверить, что все необходимые узлы содержатся в дереве и имеют правильную структуру.
