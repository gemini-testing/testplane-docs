# Подключение Testing Library

## Введение {/* #preface */}

[Testing-library][testing-library] - это коллекция инструментов для тестирования пользовательского интерфейса веб-приложений, ориентированная на создание надежных и поддерживаемых тестов, сосредотачиваясь на пользовательском поведении. Основное преимущество `testing-library` заключается в фокусе на взаимодействии с элементами интерфейса. И в testplane можно пользоваться способами поиска элемента, представленными самой библиотекой `testing-library`.

## Подключение

Для того чтобы появилась возможность использования [запросов (queries)][queries] из `testing-library` в testplane-тестах, необходимо выполнить всего несколько шагов.

1. Установите npm-пакет `@testplane/testing-library` (наша адаптация testing-library для testplane)

```bash
npm i -D @testplane/testing-library
```

2. Подключите реализацию в конфиге testplane в секции `prepareBrowser`

```typescript
// testplane.config.ts
import { setupBrowser } from "@testplane/testing-library";

export default {
    prepareBrowser(browser) {
        setupBrowser(browser);
    },

    // другие настройки testplane...
};
```

Если у вас возникнут проблемы с типами, то добавьте типы явно в `tsconfig.json`

```json
{
    "compilerOptions": {
        "types": ["testplane", "@testplane/testing-library"]
    }
}
```

## Использование

После подключения вы сможете использовать в тестах поиск по селекторам из `testing-library`, описанные в [официальной документации](https://testing-library.com/docs/queries/about/). Например, поиск элемента по его тексту

```javascript testplane=selectors-library-browser-ru fixture=selectors-library
const assert = require("node:assert/strict");

it("открывает форму репозитория по надписи на кнопке", async ({ browser }) => {
    await browser.url("/fixtures/selectors/dashboard.html");

    // Ищем кнопку по надписи, которую видит пользователь, а не по CSS-классам.
    const newRepoButton = await browser.getByText("New repository");
    await newRepoButton.click();

    const heading = await browser.$("h1");
    const title = await heading.getText();
    assert.equal(title, "Create a repository");
});
```

Если на странице две кнопки `New`, ограничьте поиск боковой панелью репозиториев:

```javascript testplane=selectors-library-element-ru fixture=selectors-library
const assert = require("node:assert/strict");

it("находит кнопку New в боковой панели репозиториев", async ({ browser }) => {
    await browser.url("/fixtures/selectors/dashboard.html");

    // Ищем внутри боковой панели репозиториев: в разделе задач тоже есть кнопка New.
    const sidebar = await browser.$(".dashboard-sidebar");
    const newRepoButton = await sidebar.getByText("New");
    await newRepoButton.click();

    const heading = await browser.$("h1");
    const title = await heading.getText();
    assert.equal(title, "Create a repository");
});
```

Полный пример использования можно найти [здесь](https://github.com/gemini-testing/testplane/tree/master/examples/).
