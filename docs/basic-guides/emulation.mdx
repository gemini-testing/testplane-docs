# Emulation

## CPU Performance

<Admonition type="warning">

This feature only works with browsers supporting _Chrome DevTools Protocol (CDP)_.

</Admonition>

The CPU speed on mobile devices is significantly slower than on computers. Therefore, to emulate CPU speed in _puppeteer_, there is a method called [emulateCPUThrottling][emulate-cpu-throttling].

### Example: Slowing Down CPU Speed by 8x {/* #example */}

Let's use this method to slow down CPU speed by 8 times:

```javascript testplane=guide-cpu-emulation fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const [page] = await (await browser.getPuppeteer()).pages();
await page.emulateCPUThrottling(8);
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
await page.emulateCPUThrottling(1);
```

[emulate-cpu-throttling]: https://pptr.dev/api/puppeteer.page.emulatecputhrottling
[cdp-session-send]: https://pptr.dev/api/puppeteer.cdpsession.send
[emulation-set-cpu-throttling-rate]: https://chromedevtools.github.io/devtools-protocol/tot/Emulation/#method-setCPUThrottlingRate

## Network Bandwidth

<Admonition type="warning">

This feature only works with browsers supporting _Chrome DevTools Protocol (CDP)_.

</Admonition>

A large number of users access services from mobile devices where internet speed can be quite slow or may even drop out intermittently. In _webdriverio_, we can limit network bandwidth using the [throttleNetwork][throttle] command, thereby testing the website's behavior under various network conditions.

Besides custom settings, the [throttleNetwork][throttle] command supports the following ready-made presets:

-   offline | online
-   GPRS
-   Regular2G | Good2G
-   Regular3G | Good3G
-   Regular4G
-   DSL
-   WiFi

### Example 1: Emulating a 2G Connection {/* #example_1 */}

Throttle the connection of a desktop Chrome tab, then check that the page remains usable:

```javascript testplane=guide-network-preset fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

await browser.throttleNetwork("Good2G");
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
```

### Example 2: Emulating a Network with Given Characteristics {/* #example_2 */}

We can also emulate a connection with specific characteristics:

```javascript testplane=guide-network-custom fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

await browser.throttleNetwork({
    offline: false,
    downloadThroughput: (10 * 1024) / 8,
    uploadThroughput: (10 * 1024) / 8,
    latency: 10,
});
await browser.url("/navigation");
assert.equal(await browser.$("h1").getText(), "Navigation");
```
