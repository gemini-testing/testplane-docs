# Mocking Network Requests

## Overview {/* #overview */}

[//]: # "TODO: add screencasts"

<Admonition type="info">

These examples use a local Chrome session with [CDP][how-to-use-cdp]. The [mock][mock] callbacks below use its CDP backend; the WebDriver BiDi backend has a different response API.

</Admonition>

The demo news page loads a logo and a script. It also has an **Archive** link that opens a new tab. Each example starts in a fresh session; none of them needs a public website.

## Example 1: Returning your own response {/* #example_1 */}

Use `fetchResponse: false` to supply a response without contacting the original resource. Navigation keeps the requested URL.

```javascript testplane=guide-mock-response fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const story = await browser.mock("**/fixtures/guides/story.html");
story.respond("Hello, world!", { fetchResponse: false, headers: { "Content-Type": "text/plain" } });
await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("body").getText(), "Hello, world!");
```

With [Puppeteer][get-puppeteer], handle the matching request and let every other request continue. Here the test has one open page.

```javascript testplane=guide-puppeteer-response fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const puppeteer = await browser.getPuppeteer();
const [page] = await puppeteer.pages();
await page.setRequestInterception(true);
page.on("request", request => {
    if (new URL(request.url()).pathname === "/fixtures/guides/story.html") {
        return request.respond({ contentType: "text/plain", body: "Hello, world!" });
    }
    return request.continue();
});

await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("body").getText(), "Hello, world!");
await page.setRequestInterception(false);
```

### Sending CDP commands directly {/* #hardcore_example */}

For lower-level control, use the CDP [Fetch domain][fetch]. The URL pattern pauses only requests for the story; `Fetch.fulfillRequest` expects a base64-encoded body.

```javascript testplane=guide-cdp-response fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const [page] = await (await browser.getPuppeteer()).pages();
const client = await page.target().createCDPSession();
client.on("Fetch.requestPaused", ({ requestId }) =>
    client.send("Fetch.fulfillRequest", {
        requestId,
        responseCode: 200,
        responseHeaders: [{ name: "Content-Type", value: "text/plain" }],
        body: Buffer.from("Hello, world!").toString("base64"),
    }),
);
await client.send("Fetch.enable", { patterns: [{ urlPattern: "*/fixtures/guides/story.html" }] });

await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("body").getText(), "Hello, world!");
await client.detach();
```

## Example 2: Canceling the logo request {/* #example_2 */}

A failed image request leaves the image without an intrinsic width, even after loading has finished.

```javascript testplane=guide-mock-abort fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const logo = await browser.mock("**/fixtures/guides/logo.svg");
logo.abort("Failed");
await browser.url("/fixtures/guides/story.html");
const image = await browser.$("#logo");
assert.equal(await image.getProperty("complete"), true);
assert.equal(await image.getProperty("naturalWidth"), 0);
```

## Example 3: Returning an HTML fixture {/* #example_3 */}

With the CDP backend, `respond` can read a file relative to the test runner’s working directory. Here it serves the archive HTML instead of the story.

```javascript testplane=guide-mock-file fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const story = await browser.mock("**/fixtures/guides/story.html");
story.respond("./fixtures/site/guides/archive.html", {
    fetchResponse: false,
    headers: { "Content-Type": "text/html" },
});
await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("h1").getText(), "Archive");
```

## Example 4: Redirecting to another page {/* #example_4 */}

Passing an absolute URL to the CDP mock redirects the browser. Unlike a body substitution, this changes the address in the browser.

```javascript testplane=guide-mock-redirect fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const story = await browser.mock("**/fixtures/guides/story.html");
const archive = new URL("/fixtures/guides/archive.html", await browser.getUrl());
story.respond(archive.href);

await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.getUrl(), archive.href);
assert.equal(await browser.$("h1").getText(), "Archive");
```

## Example 5: Editing the original response {/* #example_5 */}

To preserve the rest of the page, transform the response body rather than replacing it wholesale.

```javascript testplane=guide-mock-edit-response fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const story = await browser.mock("**/fixtures/guides/story.html");
story.respond(({ body }) => body.replaceAll("Daily report", "Preview report"));
await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("h1").getText(), "Preview report");
```

You can also select responses by content type. This example appends an instruction to JavaScript responses while leaving the original script’s behavior intact.

```javascript testplane=guide-mock-edit-scripts fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const scripts = await browser.mock("**/fixtures/guides/**", {
    headers: headers =>
        Object.entries(headers).some(
            ([name, value]) =>
                name.toLowerCase() === "content-type" && value.includes("javascript"),
        ),
});
scripts.respond(({ body }) => body + "\ndocument.body.dataset.preview = 'enabled';");

await browser.url("/fixtures/guides/story.html");
assert.equal(await browser.$("#edition").getText(), "Morning");
assert.equal(await browser.$("body").getAttribute("data-preview"), "enabled");
```

## Example 6: Recording requests across pages {/* #example_6 */}

A mock with no override records matching requests. Check for the resources you expect rather than relying on order or on a fixed number of browser requests.

```javascript testplane=guide-mock-request-list fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const traffic = await browser.mock("**/fixtures/guides/**");
await browser.url("/fixtures/guides/story.html");
const paths = traffic.calls.map(({ url }) => new URL(url).pathname);
assert.ok(paths.includes("/fixtures/guides/story.html"));
assert.ok(paths.includes("/fixtures/guides/edition.js"));
assert.ok(paths.includes("/fixtures/guides/logo.svg"));
```

Puppeteer emits request events per page. Attach a listener to each existing page, then to the newly opened archive tab before triggering its next request.

```javascript testplane=guide-puppeteer-request-list fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

const puppeteer = await browser.getPuppeteer();
const paths = new Set();
const track = page => page.on("request", req => paths.add(new URL(req.url()).pathname));
for (const page of await puppeteer.pages()) track(page);

await browser.url("/fixtures/guides/story.html");
const opened = puppeteer.waitForTarget(target => target.url().endsWith("/archive.html"));
await browser.$("a[target='_blank']").click();
const archive = await (await opened).page();
track(archive);
await archive.click("#details");
await archive.waitForFunction(() => document.querySelector("output").textContent === "Evening");

assert.ok(paths.has("/fixtures/guides/edition.js"));
assert.ok(paths.has("/fixtures/guides/details.json"));
```

## Example 7: Mocking the google.com Resource in All Chrome Tests {/* #example_7 */}

To avoid manually mocking the same resources in all tests, you can use the [testplane-global-hook][testplane-global-hook] plugin. Configure it appropriately in the Testplane config:

```javascript
// .testplane.conf.js
module.exports = {
    plugins: {
        "testplane-global-hook": {
            enabled: true,

            beforeEach: async function ({ browser }) {
                // Check that the browser name starts with "chrome"
                if (!/^chrome$/i.test(browser.capabilities.browserName)) {
                    return;
                }

                // Mocking the request to google.com
                const mock = await browser.mock("https://google.com");
                mock.respond("hello world", { fetchResponse: false });
            },

            afterEach: function ({ browser }) {
                // Clear all mocks in the current session
                browser.mockRestoreAll();
            },
        },

        // other Testplane plugins...
    },

    // other Testplane settings...
};
```

The test code will now only contain the URL transition:

```javascript
// Explicitly indicate that the test is only executed in browsers whose name starts with chrome
testplane.only.in(/^chrome/);
it("should mock google.com inside global before each", async function ({ browser }) {
    await browser.url("https://google.com");
});
```
