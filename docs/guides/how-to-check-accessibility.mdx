# Accessibility Testing

## Overview {/* #overview */}

<Admonition type="warning">
This recipe uses Puppeteer over the _Chrome DevTools Protocol (CDP)_.

Read more details in the section “[How to Use CDP in Testplane][how-to-use-cdp]”

</Admonition>

[Accessibility tree][accessibility-tree] is an accessibility tree that contains a hierarchical structure of accessible objects. Unlike the DOM tree, which is intended for browsers, the accessibility tree is intended for [screen readers][screen-reader] and other tools that help people with disabilities interact with websites.

To obtain such a tree, _puppeteer_ has a special [Accessibility class][puppeteer-accessibility].

## Example {/* #example */}

Take a snapshot of the local portal. Check the role and accessible name of the page, then find the links a screen reader can announce.

```javascript testplane=guide-accessibility-tree fixture=guides-page transport=cdp
const assert = require("node:assert/strict");

it("reads the accessibility tree of the portal", async ({ browser }) => {
    // Get the Puppeteer connection for the current Testplane session.
    const puppeteer = await browser.getPuppeteer();

    // Only one tab is open in this test, so the first page is the active one.
    const [page] = await puppeteer.pages();
    await browser.url("/fixtures/guides/accessibility.html");

    // Print the accessibility tree, not the DOM: its nodes have roles and accessible names.
    const snapshot = await page.accessibility.snapshot();
    console.log(JSON.stringify(snapshot, null, 2));

    assert.equal(snapshot.role, "RootWebArea");
    assert.equal(snapshot.name, "Team portal");

    // Select links by role; the snapshot can also contain text nodes.
    const links = snapshot.children.filter(node => node.role === "link");
    const names = links.map(link => link.name);
    assert.deepEqual(names, ["Sign in", "Inbox", "Drive", "Finance", "Help"]);
});
```
