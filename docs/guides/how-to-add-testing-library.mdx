# Installing Testing Library

## Introduction {/* #preface */}

[Testing-library][testing-library] is a collection of tools for testing web application user interfaces, focused on creating reliable and maintainable tests by emphasizing user behavior. The main advantage of `testing-library` is its focus on interaction with interface elements. And in testplane, you can use the element search methods provided by the `testing-library` itself.

## Installation

To be able to use [queries][queries] from `testing-library` in Testplane tests, you only need to follow a few steps.

1. Install the npm package `@testplane/testing-library` (our adapter package for the original testing-library)

```bash
npm i -D @testplane/testing-library
```

2. Include it in the Testplane config in the `prepareBrowser` section:

```typescript
// testplane.config.ts
import { setupBrowser } from "@testplane/testing-library";

export default {
    prepareBrowser(browser) {
        setupBrowser(browser);
    },

    // other settings for testplane...
};
```

If you have problems with types, add types explicitly to `tsconfig.json`

```json
{
    "compilerOptions": {
        "types": ["testplane", "@testplane/testing-library"]
    }
}
```

## Usage

You can search by selectors from `testing-library` as described in the [official docs](https://testing-library.com/docs/queries/about/). For example, here's how to search for an element by its text:

```javascript testplane=selectors-library-browser fixture=selectors-dashboard
const assert = require("node:assert/strict");

const create = await browser.getByText("New repository");
await create.click();
assert.equal(await browser.$("h1").getText(), "Create a repository");
```

If two buttons on the dashboard say `New`, scope the query to the repositories sidebar:

```javascript testplane=selectors-library-element fixture=selectors-dashboard
const assert = require("node:assert/strict");

const sidebar = await browser.$(".dashboard-sidebar");
const create = await sidebar.getByText("New");
await create.click();
assert.equal(await browser.$("h1").getText(), "Create a repository");
```

For a complete usage example, visit [this link](https://github.com/gemini-testing/testplane/tree/master/examples/).
