# expect for the browser

The examples use the app's configured `baseUrl` and start on a page titled `Task list`.

## toHaveUrl

Checks if the browser is on the specified page.

For example:

```javascript testplane=expect-to-have-url fixture=matchers-page
const expectedUrl = new URL("/navigation", browser.options.baseUrl).href;
await browser.url("/navigation");
await expect(browser).toHaveUrl(expectedUrl);
```

## toHaveUrlContaining

Checks if the specified substring is contained in the URL of the page the browser is on.

For example:

```javascript testplane=expect-to-have-url-containing fixture=matchers-page
await browser.url("/navigation");
await expect(browser).toHaveUrlContaining("/navigation");
```

## toHaveTitle

Checks if the website has the specified title.

For example:

```javascript testplane=expect-to-have-title fixture=matchers-page
await expect(browser).toHaveTitle("Task list");
```

## toHaveTitleContaining

Checks if the specified substring is contained in the website's title.

For example:

```javascript testplane=expect-to-have-title-containing fixture=matchers-page
await expect(browser).toHaveTitleContaining("Task");
```
