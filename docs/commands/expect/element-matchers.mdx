# expect for elements

The examples start on a task page with a username field, action buttons, a three-stage workflow and a list of five tasks.

## toBeDisplayed

Calls [isDisplayed](../../element/isDisplayed) on the given element.

For example:

```javascript testplane=expect-to-be-displayed fixture=matchers-page
const input = await browser.$("#username");
await expect(input).toBeDisplayed();
```

## toHaveText

Checks if the element's text matches the specified value.

It can also be called with an array as a parameter in case the element can have different texts.

For example:

```javascript testplane=expect-to-have-text fixture=matchers-page
await browser.url("/fixtures/matchers/tasks.html");
const heading = await browser.$("h1");
await expect(heading).toHaveText("Task list");

// Use an array if either heading is acceptable.
await expect(heading).toHaveText(["Task list", "No tasks yet"]);
```

## toHaveTextContaining

Checks if the element's text contains the specified substring.

It can also be called with an array as a parameter in case the element can have different texts.

## toHaveChildren

Checks the number of child elements of the given element using the [element.$$('./\*')](../../element/_dollardollar) command.

Pass an options object in this version of expect-webdriverio: calling the matcher without an argument throws. An empty object means at least one child.

For example:

```javascript testplane=expect-to-have-children fixture=matchers-page
const stages = await browser.$("#stages");
await expect(stages).toHaveChildren({}); // At least one child.

// Or state the same lower bound explicitly:
await expect(stages).toHaveChildren({ gte: 1 });
```

```javascript testplane=expect-to-have-children-count fixture=matchers-page
const stages = await browser.$("#stages");
await expect(stages).toHaveChildren(3); // Exactly three stages.

// Equivalent when using an options object:
await expect(stages).toHaveChildren({ eq: 3 });
```

## toBeElementsArrayOfSize

Checks the number of elements obtained using the [$$](../../element/_dollardollar) command.

For example:

```javascript testplane=expect-to-be-elements-array-of-size fixture=matchers-page
const listItems = await browser.$$("#tasks > li");
await expect(listItems).toBeElementsArrayOfSize(5); // Exactly five tasks in the list.
```

```javascript testplane=expect-to-be-elements-array-of-size-limit fixture=matchers-page
const assert = require("node:assert/strict");

const listItems = await browser.$$("#tasks > li");
await expect(listItems).toBeElementsArrayOfSize({ lte: 10 });

// To check the current length directly, use a plain assertion:
assert.ok(listItems.length <= 10);
```
