# saveState

<Version version="8.33.0" />

## Overview {/* #overview */}

Browser command that saves session state (cookies, local and session storages).

## Usage {/* #usage */}

This command returns a state of the page state, including cookies, localStorage, and sessionStorage.
You can use parameters to exclude specific types of data if needed.

If you provide the `path` parameter, the state dump will be saved to a file.
The saved state can later be restored using the [restoreState](../restoreState) command.

```typescript testplane=browser-save-state-data fixture=browser-page
import type { SaveStateData } from "testplane";
const assert = require("node:assert/strict");

await browser.url("/fixtures/browser/session.html");
const stateDump: SaveStateData = await browser.saveState({
    path: "./artifacts/stateDump.json",
    cookies: true,
    localStorage: true,
    sessionStorage: true,
});

const origin = new URL(await browser.getUrl()).origin;
assert.equal(stateDump.cookies?.find(cookie => cookie.name === "theme")?.value, "dark");
assert.equal(stateDump.framesData?.[origin]?.localStorage?.theme, "dark");
assert.equal(stateDump.framesData?.[origin]?.sessionStorage?.draft, "hello");
```

## Usage Examples {/* #examples */}

Save state in file.

```typescript testplane=browser-save-state-file fixture=browser-page
const assert = require("node:assert/strict");

it("should write only selected cookies to the state file", async ({ browser }) => {
    await browser.url("/");
    await browser.setCookies([
        { name: "theme", value: "dark" },
        { name: "temporary", value: "1" },
    ]);

    const path = "./artifacts/stateDump.json";
    const host = new URL(await browser.getUrl()).hostname;
    await browser.saveState({
        path,
        cookieFilter: ({ domain, name }) => domain === host && name === "theme",
    });

    const stateDump = await browser.getState({ path });
    assert.deepEqual(
        stateDump.cookies.map(({ name, value }) => [name, value]),
        [["theme", "dark"]],
    );
});
```
