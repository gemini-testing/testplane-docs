# overwriteCommand

## Overview {/* #overview */}

Use the `overwriteCommand` command to override existing commands of the browser or an element.

<Admonition type="info">
    Also see the recipe "[How to add custom commands][how-to-add-custom-commands]".
</Admonition>

## Usage {/* #usage */}

```javascript
await browser.overwriteCommand(name, callback, elementScope);
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-overwrite-command fixture=browser-page
const assert = require("node:assert/strict");

describe("pause", () => {
    beforeEach(async ({ browser }) => {
        // Log the duration before pausing and return it after the original command finishes.
        await browser.overwriteCommand("pause", async function (origPauseFunction, ms) {
            console.log(`Sleeping for ${ms}`);
            await origPauseFunction(ms);
            return ms;
        });
    });

    it("should use the overwritten pause command", async ({ browser }) => {
        // Use the overwritten command.
        const duration = await browser.pause(100); // outputs: "Sleeping for 100"
        assert.equal(duration, 100);
    });
});
```
