# call

## Overview {/* #overview */}

Use the `call` command to perform any asynchronous action in tests.

This command is treated as a synchronous function. It accepts a promise and halts its execution until the promise is resolved.

## Usage {/* #usage */}

```javascript
await browser.call(callback);
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-call fixture=browser-page
const assert = require("node:assert/strict");

const http = require("node:http");

it("should wait for asynchronous Node.js APIs", async ({ browser }) => {
    await browser.url("/");
    const url = new URL("/api/items", await browser.getUrl());

    // With a third-party library that returns a promise, return that promise from the callback.
    // For example, a test can prepare its data in a backend or database this way.
    // Here we read the fixture from the backend using fetch.
    const data = await browser.call(async () => {
        const response = await fetch(url);
        return response.json();
    });
    assert.equal(data.source, "original");

    // A library that only takes a callback needs a Promise wrapper.
    // Resolve it when the response arrives, or reject it on error.
    const status = await browser.call(() => {
        return new Promise((resolve, reject) => {
            const request = http.get(url, response => {
                response.resume();
                resolve(response.statusCode);
            });
            request.on("error", reject);
        });
    });
    assert.equal(status, 200);
});
```
