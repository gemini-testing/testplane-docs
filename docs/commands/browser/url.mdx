# url

## Overview {/* #overview */}

Use the `url` command to navigate to the specified URL in the browser.

If [baseUrl][base-url] is specified in the configuration, it will be added to the `url` parameter using the Node.js method [url.resolve()][url-resolve].

Calling `browser.url()` with the same URL as before will reload the page.

## Usage {/* #usage */}

```javascript
await browser.url(url);
```

## Usage Examples {/* #examples */}

**url.js**

```javascript testplane=browser-navigate fixture=browser-page
const assert = require("node:assert/strict");

// Navigate to the URL.
await browser.url("/navigation");

// Read the current URL, including the path used above.
const url = await browser.getUrl();
assert.equal(new URL(url).pathname, "/navigation");
```

**baseUrlResolutions.js**

```javascript testplane=browser-resolve-url fixture=browser-base-url
const assert = require("node:assert/strict");

// Assume baseUrl ends in /site/. The trailing slash keeps site in relative URLs.
const { baseUrl } = await browser.getConfig();

// An absolute URL opens as it is.
const absolute = new URL("/frame", baseUrl).href;
await browser.url(absolute);
assert.equal(await browser.getUrl(), absolute);

// A path without a leading slash is relative to the directory in baseUrl.
await browser.url("relative");
assert.equal(new URL(await browser.getUrl()).pathname, "/site/relative");

// A leading slash starts at the root of the same origin, not at /site/.
await browser.url("/rootRelative");
assert.equal(new URL(await browser.getUrl()).pathname, "/rootRelative");
```
