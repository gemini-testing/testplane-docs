# getPuppeteer

## Overview {/* #overview */}

Use the `getPuppeteer` command to get an instance of the browser's [Puppeteer][puppeteer] in order to execute specialized commands with it.

Puppeteer commands return promises; await them inside the test.

<Admonition type="warning">
The _getPuppeteer_ command only works when using _Chrome DevTools Protocol (CDP)_.

Read more in the section "[How to use Chrome DevTools Protocol in testplane][how-to-use-cdp]".

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.getPuppeteer();
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-get-puppeteer fixture=browser-page
const assert = require("node:assert/strict");

it("should use Puppeteer on the current page", async ({ browser }) => {
    await browser.url("/");
    const url = await browser.getUrl();
    const puppeteerBrowser = await browser.getPuppeteer();

    // Switch to Puppeteer and find the page opened by Testplane.
    const metrics = await browser.call(async () => {
        const pages = await puppeteerBrowser.pages();
        const page = pages.find(page => page.url() === url);
        assert.equal(await page.title(), "Command examples");
        await page.setGeolocation({ latitude: 59.95, longitude: 30.31667 });

        return page.metrics();
    });

    // LayoutCount is the number of layouts; the exact value depends on the page.
    console.log(metrics.LayoutCount);
    assert.ok(Number.isInteger(metrics.LayoutCount) && metrics.LayoutCount >= 0);
    assert.ok(metrics.Nodes > 0);
});
```
