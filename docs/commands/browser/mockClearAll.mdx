# mockClearAll

## Overview {/* #overview */}

Use the `mockClearAll` command to reset all stored information in registered mocks. Mocks are registered using the [mock][mock] command.

## Usage {/* #usage */}

```typescript
await browser.mockClearAll();
```

## Usage Examples {/* #examples */}

```typescript testplane=browser-mock-clear-all fixture=browser-mock
const assert = require("node:assert/strict");

it("clears the call history for every mock", async ({ browser }) => {
    const items = await browser.mock("/api/items");
    const other = await browser.mock("/api/other");
    await browser.execute(async () => {
        await fetch("/api/items");
        await fetch("/api/other");
    });
    await browser.waitUntil(() => items.calls.length === 1 && other.calls.length === 1);

    await browser.mockClearAll();
    assert.deepEqual([items.calls.length, other.calls.length], [0, 0]);
    await items.restore();
    await other.restore();
});
```
