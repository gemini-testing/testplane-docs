# mockClearAll

## Overview {/* #overview */}

Use the `mockClearAll` command to reset all stored information in registered mocks. Mocks are registered using the [mock][mock] command.

## Usage {/* #usage */}

```typescript
await browser.mockClearAll();
```

## Usage Examples {/* #examples */}

```typescript testplane=browser-mock-clear-all fixture=browser-mock
const assert = require("node:assert/strict");

it("should clear all mocks", async ({ browser }) => {
    const docMock = await browser.mock("/frame");
    const jsMock = await browser.mock("/fixtures/browser/banner.js");
    const calls = () => [docMock.calls.length, jsMock.calls.length];

    await browser.url("/fixtures/browser/resources.html");
    const load = await browser.$("button");

    await load.click();
    await browser.waitUntil(async () => (await browser.$("output").getText()) === "1");
    assert.deepEqual(calls(), [1, 1]); // both resources were requested

    await load.click();
    await browser.waitUntil(async () => (await browser.$("output").getText()) === "2");
    assert.deepEqual(calls(), [2, 1]); // the browser reuses the imported JavaScript module

    await browser.mockClearAll();
    assert.deepEqual(calls(), [0, 0]); // both histories were cleared
    await browser.mockRestoreAll();
});
```
