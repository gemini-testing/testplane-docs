# setTimeout

## Overview {/* #overview */}

Use the `setTimeout` command to set timeouts for element searches on the page, document load waits, and script executions through the [execute][execute] or [executeAsync][execute-async] commands.

## Usage {/* #usage */}

```javascript
await browser.setTimeout({ implicit, pageLoad, script });
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>implicit</td><td>Number</td><td>Time in milliseconds for retrying element location when searching for an element.</td></tr>
<tr><td>pageLoad</td><td>Number</td><td>Time to wait for the document to load, in milliseconds.</td></tr>
<tr><td>script</td><td>Number</td><td>Timeout for scripts run using [execute][execute] or [executeAsync][execute-async], in milliseconds.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```javascript testplane=browser-set-timeout fixture=browser-page
const assert = require("node:assert/strict");

it("should change timeouts before running a long script", async ({ browser }) => {
    await browser.setTimeout({
        pageLoad: 10000,
        script: 5000,
    });

    // The script completes asynchronously within the new script timeout.
    const message = await browser.executeAsync(done => {
        setTimeout(() => done("Wake me up before you go!"), 1000);
    });
    assert.equal(message, "Wake me up before you go!");

    const timeouts = await browser.getTimeouts();
    assert.equal(timeouts.pageLoad, 10000);
    assert.equal(timeouts.script, 5000);
});
```
