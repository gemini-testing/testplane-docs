# getCookies

## Overview {/* #overview */}

Use the `getCookies` command to get all or specific cookies on the current page.

To get specific cookies, you need to specify the cookie name as a string or a list of cookie names as an array of strings.

## Usage {/* #usage */}

```javascript
await browser.getCookies(names);
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-get-cookies fixture=browser-page
const assert = require("node:assert/strict");

// Show only names and values; cookies also have fields such as domain, path and expiry.
const namesAndValues = cookies =>
    cookies
        .map(({ name, value }) => ({ name, value }))
        .sort((a, b) => a.name.localeCompare(b.name));

it("should read one cookie or all cookies", async ({ browser }) => {
    const initial = [
        { name: "test", value: "123" },
        { name: "test2", value: "456" },
    ];
    await browser.setCookies(initial);

    const testCookie = await browser.getCookies(["test"]);
    console.log(namesAndValues(testCookie));
    // Output:
    // [
    //     { name: "test", value: "123" }
    // ]
    assert.deepEqual(namesAndValues(testCookie), [initial[0]]);

    const allCookies = await browser.getCookies();
    console.log(namesAndValues(allCookies));
    // Output:
    // [
    //     { name: "test", value: "123" },
    //     { name: "test2", value: "456" }
    // ]
    assert.deepEqual(namesAndValues(allCookies), initial);
});
```
