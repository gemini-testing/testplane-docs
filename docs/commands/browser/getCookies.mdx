# getCookies

## Overview {/* #overview */}

Use the `getCookies` command to get all or specific cookies on the current page.

To get specific cookies, you need to specify the cookie name as a string or a list of cookie names as an array of strings.

## Usage {/* #usage */}

```javascript
await browser.getCookies(names);
```

## Command Parameters {/* #parameters */}

## Usage Examples {/* #examples */}

```javascript testplane=browser-get-cookies fixture=browser-page
const assert = require("node:assert/strict");

it("reads one cookie or all cookies", async ({ browser }) => {
    await browser.setCookies([
        { name: "test", value: "123" },
        { name: "test2", value: "456" },
    ]);
    const [cookie] = await browser.getCookies("test");
    assert.equal(cookie.value, "123");
    const cookies = await browser.getCookies();
    assert.deepEqual(cookies.map(({ name }) => name).sort(), ["test", "test2"]);
});
```
