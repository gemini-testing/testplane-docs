# clearSession

## Overview {/* #overview */}

Browser command that clears session state (deletes cookies, clears local and session storages).

## Usage {/* #usage */}

```javascript
await browser.clearSession();
```

## Usage Examples {/* #examples */}

```typescript testplane=browser-clear-session fixture=browser-page
const assert = require("node:assert/strict");

it("should clear cookies, localStorage and sessionStorage", async ({ browser }) => {
    await browser.url("/fixtures/browser/session.html");

    assert.equal((await browser.getCookies()).length, 1);
    assert.equal(await browser.execute(() => localStorage.length), 2);
    assert.equal(await browser.execute(() => sessionStorage.length), 1);

    await browser.clearSession();

    assert.equal((await browser.getCookies()).length, 0);
    assert.equal(await browser.execute(() => localStorage.length), 0);
    assert.equal(await browser.execute(() => sessionStorage.length), 0);
});
```
