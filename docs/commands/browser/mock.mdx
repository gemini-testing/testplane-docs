# mock

## Overview {/* #overview */}

Use the `mock` command to mock the response to a request.

You can enable mocking depending on the URL, headers, or status code. Calling the `mock` method returns a stub object that you can use to modify the response from the web resource. With the stub object, you can return a mock response or abort the request.

There are 3 ways to modify the response:

-   return a custom JSON object (e.g., to mock an API response);
-   replace a text response, for example the contents of a script;
-   redirect to another URL and return the response from there.

<Admonition type="warning">
The examples below use WebDriver BiDi unless marked WebDriver Classic/CDP. The two implementations support different response-header and request-body filters.

Read more in the section "[How to use Chrome DevTools Protocol in testplane][how-to-use-cdp]".

Also, see the recipe "[How to intercept requests and responses][how-to-intercept-requests-and-responses]".

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.mock(url, { method, requestHeaders, responseHeaders, statusCode });
```

    <td>headers, postData</td>
    <td>Object, String or Function</td>
    <td>
        In WebDriver Classic/CDP, `headers` filters response headers and `postData` filters the
        request body. In BiDi, use `responseHeaders` for response headers; request-body filters are
        not supported.
    </td>
</tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```javascript testplane=browser-mock-resources fixture=browser-mock
const assert = require("node:assert/strict");

it("should mock network resources", async ({ browser }) => {
    // Match a URL with a static string.
    const userListMock = await browser.mock("/fixtures/browser/users.json");

    // Narrow the match to requests carrying a specific header.
    const strictMock = await browser.mock("/api/items", {
        requestHeaders: { "x-example": "list" },
        statusCode: 200,
    });

    // Use a comparator to match a range of status codes and JSON responses.
    const apiMock = await browser.mock("/api/other", {
        statusCode: code => code >= 200 && code <= 203,
        responseHeaders: headers =>
            Object.entries(headers).some(
                ([name, value]) =>
                    name.toLowerCase() === "content-type" && value.includes("application/json"),
            ),
    });

    await browser.execute(async () => {
        await fetch("/fixtures/browser/users.json");
        await fetch("/api/items"); // no matching header
        await fetch("/api/items", { headers: { "x-example": "list" } });
        await fetch("/api/other");
    });
    await browser.waitUntil(() =>
        [userListMock, strictMock, apiMock].every(mock => mock.calls.length === 1),
    );
    await browser.mockRestoreAll();
});

it("should modify API responses", async ({ browser }) => {
    // Filter by HTTP method.
    const todoMock = await browser.mock("/api/items", { method: "get" });
    const todos = [{ title: "Injected Todo", completed: false }];

    const fetchTodos = () =>
        browser.execute(async () => {
            const response = await fetch("/api/items");
            return {
                status: response.status,
                header: response.headers.get("x-custom-header"),
                body: await response.json(),
            };
        });

    // Replace the response body with a predefined list.
    await todoMock.respond(todos);
    assert.deepEqual((await fetchTodos()).body, todos);

    // You can also change the status code and response headers.
    await todoMock.respond(todos, { statusCode: 404, headers: { "x-custom-header": "foobar" } });
    assert.deepEqual(await fetchTodos(), { status: 404, header: "foobar", body: todos });
    await todoMock.restore();
});

it("should modify text assets", async ({ browser }) => {
    const scriptMock = await browser.mock("/fixtures/browser/banner.js");
    await scriptMock.respond("window.banner = 'Preview';");

    await browser.url("/fixtures/browser/preview.html");
    assert.equal(await browser.execute(() => window.banner), "Preview");
    await scriptMock.restore();
});

it("should replace a script with a local JavaScript file", async ({ browser }) => {
    const { readFile } = require("node:fs/promises");
    const scriptMock = await browser.mock("/fixtures/browser/banner.js");

    // BiDi responds with the given text: read the file, do not pass its path as the response.
    const source = await readFile("fixtures/site/browser/preview-banner.js", "utf8");
    await scriptMock.respond(source);

    await browser.url("/fixtures/browser/preview.html");
    assert.equal(await browser.execute(() => window.banner), "Release notes");
    await scriptMock.restore();
});

it("should redirect web resources", async ({ browser }) => {
    const origin = new URL(await browser.getUrl()).origin;
    const headerMock = await browser.mock("/fixtures/browser/header.svg");
    await headerMock.redirect(new URL("/fixtures/browser/banner.svg", origin).href);

    const pageMock = await browser.mock("/original");
    await pageMock.redirect(new URL("/fixtures/browser/preview.html", origin).href);
    await browser.url("/original");

    assert.equal(await browser.getTitle(), "Preview");
    const header = await browser.$("img");
    assert.equal(await header.getProperty("naturalWidth"), 32); // width of banner.svg
    await browser.mockRestoreAll();
});
```

For the WebDriver Classic/CDP form that accepts a file path directly, see [Returning an HTML fixture](../../../guides/how-to-intercept-requests-and-responses#example_3).

In a WebDriver Classic session with CDP, you can also match the body of a POST request:

```javascript testplane=browser-mock-post-data fixture=browser-page transport=cdp
const assert = require("node:assert/strict");

it("should match the request payload in WebDriver Classic", async ({ browser }) => {
    const endpoint = new URL("/api/items", await browser.getUrl()).href;
    const postMock = await browser.mock(endpoint, {
        method: "post",
        headers: { "Content-Type": "application/json" },
        postData: data => typeof data === "string" && data.includes("foo"),
    });

    await browser.execute(async () => {
        await fetch("/api/items", { method: "POST", body: "other" });
        await fetch("/api/items", { method: "POST", body: "foobar" });
    });

    await browser.waitUntil(() => postMock.calls.length === 1);
    assert.equal(postMock.calls[0].postData, "foobar");
    await postMock.restore();
});
```
