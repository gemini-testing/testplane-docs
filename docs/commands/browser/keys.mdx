# keys

## Overview {/* #overview */}

Use the `keys` command to send a sequence of key presses to the active element.

You can also use symbols like “Left Arrow” or “Right Arrow”. They will be automatically transformed to the corresponding unicode characters. You can see all supported characters [here][keyboard-actions].

Modifiers such as `Ctrl`, `Shift`, `Alt`, and `Meta` remain pressed until you release them by calling the function again. However, modifying clicks requires using the [performActions][perform-actions] method from the WebDriver Actions API.

## Usage {/* #usage */}

```javascript
await browser.keys(value);
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-keys fixture=browser-clipboard
const assert = require("node:assert/strict");

it("copies text out of the active element", async ({ browser }) => {
    const modifier = browser.capabilities.platformName.toLowerCase().includes("mac")
        ? "Meta"
        : "Control";

    // Select and copy the text from the input.
    const username = await browser.$("#username");
    await username.setValue("anonymous");
    await browser.keys([modifier, "a"]);
    await browser.keys([modifier, "c"]);

    // Paste into another input to check what was copied.
    const copy = await browser.$("#copy");
    await copy.click();
    await browser.keys([modifier, "v"]);
    assert.equal(await copy.getValue(), "anonymous");

    // Passing a string types text in place of the selection.
    await browser.keys([modifier, "a"]);
    await browser.keys("guest");
    assert.equal(await copy.getValue(), "guest");
});
```
