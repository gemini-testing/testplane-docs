# mockRestoreAll

## Overview {/* #overview */}

Use the `mockRestoreAll` command to restore the information and behavior in registered mocks to their original state. Mocks are registered using the [mock][mock] command.

## Usage {/* #usage */}

```typescript
await browser.mockRestoreAll();
```

## Usage Examples {/* #examples */}

```typescript testplane=browser-mock-restore-all fixture=browser-mock
const assert = require("node:assert/strict");

it("should restore all mocks", async ({ browser }) => {
    const origin = new URL(await browser.getUrl()).origin;
    const pageMock = await browser.mock("/original");
    const previewMock = await browser.mock("/fixtures/browser/preview.html");
    await pageMock.redirect(new URL("/frame", origin).href);
    await previewMock.redirect(new URL("/frame", origin).href);

    await browser.url("/original");
    assert.equal(await browser.getTitle(), "Frame");
    await browser.url("/fixtures/browser/preview.html");
    assert.equal(await browser.getTitle(), "Frame");

    await browser.mockRestoreAll();

    // Both URLs now return their original pages.
    await browser.url("/original");
    assert.equal(await browser.getTitle(), "Command examples");
    await browser.url("/fixtures/browser/preview.html");
    assert.equal(await browser.getTitle(), "Preview");
});
```
