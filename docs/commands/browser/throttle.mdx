# throttle

## Overview {/* #overview */}

Deprecated alias of [throttleNetwork](./throttleNetwork.mdx). Limits network throughput through CDP/Puppeteer; it is not equivalent to [emulate("onLine")](./emulate.mdx). Use `throttleNetwork` for new code.

## Usage {/* #usage */}

`await browser.throttle(profile)`

## Command parameters {/* #parameters */}

Parameters match [throttleNetwork](./throttleNetwork.mdx#parameters). Pass a profile name: `offline`, `online`, `GPRS`, `Regular2G`, `Good2G`, `Regular3G`, `Good3G`, `Regular4G`, `DSL`, `WiFi`. Names contain no spaces.

Or pass an object with `offline` (boolean), `latency` (milliseconds), `downloadThroughput` and `uploadThroughput` (bytes per second, `-1` disables throughput limits). Returns `Promise<void>`.

## Limitations {/* #limitations */}

Requires a browser with CDP/Puppeteer access. The implementation selects the first Puppeteer page: use one tab and `isolation: false` for this example, and navigate first.

In Testplane 9.3.2 / WDIO 9.6.2 / Chrome 150, the `online` profile did not restore connectivity after `offline`. Set `testsPerSession: 1` to prevent limits leaking into the next test. See [throttleNetwork](./throttleNetwork.mdx#limitations).

## Example {/* #examples */}

Set `baseUrl` to a test HTTP server that returns `200` at the root path. The example uses a new session for each test.

```javascript
const assert = require("node:assert/strict");

it("throttle: use the deprecated alias in an isolated session", async ({ browser }) => {
    await browser.url("/");
    await browser.throttle("Good3G");
    const status = await browser.execute(
        async () => (await fetch("/?throttled", { cache: "no-store" })).status,
    );
    assert.equal(status, 200);
});
```
