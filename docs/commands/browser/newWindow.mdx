# newWindow

## Overview {/* #overview */}

Use the `newWindow` command to open a new window in the browser.

This command is equivalent to the [window.open()][window-open] function.

Note that this command will automatically switch you to the new window upon execution.

<Admonition type="warning">
    The _newWindow_ command does not work in mobile environments (!)
</Admonition>

Use `{ type: "tab" }` or `{ type: "window" }` to select the kind of browsing context. `windowName` and `windowFeatures` are deprecated and only supported in WebDriver Classic.

## Usage {/* #usage */}

```javascript
await browser.newWindow(url, { windowName, windowFeatures });
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-new-window fixture=browser-page
const assert = require("node:assert/strict");

it("should open a new tab", async ({ browser }) => {
    await browser.url("/");
    const original = await browser.getWindowHandle();
    assert.equal(await browser.getTitle(), "Command examples"); // original tab

    const frameUrl = new URL("/frame", await browser.getUrl()).href;
    await browser.newWindow(frameUrl, { type: "tab" });
    assert.equal(await browser.getTitle(), "Frame"); // new tab

    await browser.closeWindow();
    await browser.switchToWindow(original);
    assert.equal(await browser.getTitle(), "Command examples"); // back in the original tab
});
```

In WebDriver Classic, pass a name and window features as options:

```javascript testplane=browser-new-named-window fixture=browser-page transport=cdp
const assert = require("node:assert/strict");

it("should open a named window in WebDriver Classic", async ({ browser }) => {
    const url = new URL("/frame", await browser.getUrl()).href;
    await browser.newWindow(url, {
        windowName: "Preview",
        windowFeatures: "width=420,height=230,resizable,scrollbars=yes",
    });

    const name = await browser.execute(() => window.name);
    assert.equal(name, "Preview");
    assert.equal(await browser.getTitle(), "Frame");
});
```
