# runStep

## Overview {/* #overview */}

Use the `runStep` command to obtain a human-readable execution history of the test, which will automatically be displayed in the [html-reporter][reporter].
Steps can be nested.

## Usage {/* #usage */}

```typescript
await browser.runStep(stepName, stepCb);
```

## Usage Examples {/* #examples */}

```typescript testplane=browser-nested-steps fixture=browser-page
const assert = require("node:assert/strict");

it("keeps the missing element error from a nested step", async ({ browser }) => {
    await browser.runStep("prepare page", async () => {
        await browser.url("/");
        await browser.setCookies({ name: "cart", value: "empty" });
    });

    await assert.rejects(
        () =>
            browser.runStep("make an order", async () => {
                await browser.runStep("navigate to the shopping cart", async () => {
                    await browser.$("not-exist-selector").click();
                });
            }),
        /not-exist-selector/,
    );
});
```

The assertion expects the missing element error. Without `assert.rejects`, the error would fail the test; the nested steps make its origin visible in the report:

```
- testplane: init browser
- prepare page
- make an order
    - navigate to the shopping cart
        - $("not-exist-selector")
        - click()
            - waitForExist
```

In this example step `prepare page` is collapsed, because it is completed successfully.

You can also return values from step:

```typescript testplane=browser-step-result fixture=browser-page
const assert = require("node:assert/strict");

const parsedPage = await browser.runStep("parse page", async () => {
    const heading = await browser.$("h1").getText();
    return { heading };
});

assert.equal(parsedPage.heading, "Command examples");
```
