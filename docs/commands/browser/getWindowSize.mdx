# getWindowSize

## Overview {/* #overview */}

Use the `getWindowSize` command to get the size of the browser window.

## Usage {/* #usage */}

```javascript
await browser.getWindowSize();
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-get-window-size fixture=browser-page
const assert = require("node:assert/strict");

it("returns the current window dimensions", async ({ browser }) => {
    await browser.setWindowSize(1024, 768);
    assert.deepEqual(await browser.getWindowSize(), { width: 1024, height: 768 });
});
```
