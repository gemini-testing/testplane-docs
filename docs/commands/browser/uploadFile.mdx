# uploadFile

## Overview {/* #overview */}

Use the `uploadFile` command to upload a file to a _[Selenium Standalone][selenium-file]_ server or to the browser via its driver (e.g., [Chromedriver][chromedriver]).

<Admonition type="warning">
    The _uploadFile_ command is only supported when using [Selenium Grid][selenium-grid] or
    [Chromedriver][chromedriver]. This is because it uses an unofficial protocol feature that is
    currently implemented only in _Chrome_ and when running on [Selenium Grid][selenium-grid].
</Admonition>

## Usage {/* #usage */}

```javascript
await browser.uploadFile(localPath);
```

## Usage Examples {/* #examples */}

The example uploads the test file itself to your Selenium Grid and checks its name in the file input.

```javascript testplane=browser-upload-file suite=selenium
const assert = require("node:assert/strict");
const path = require("node:path");

it("uploadFile: select a local file on a Grid node", async ({ browser }) => {
    await browser.url("data:text/html,<input type=file>");
    const remotePath = await browser.uploadFile(__filename);
    await browser.$("input[type=file]").setValue(remotePath);

    const name = await browser.execute(() => document.querySelector("input").files[0]?.name);
    assert.equal(name, path.basename(__filename));
});
```
