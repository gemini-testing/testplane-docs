# react$$

## Overview {/* #overview */}

Use the `react$$` command to find multiple React components on the page by their actual name, while filtering them by props and state.

<Admonition type="warning">
The _react$_ command only works in applications that use _React v16.x._

Read more about React selectors in the recipe "[How to use selectors][how-to-use-selectors]".

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.react$$(reactComponentSelector, { props, state });
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-react-components fixture=browser-page
const assert = require("node:assert/strict");

it("finds the calculator operator buttons by prop", async ({ browser }) => {
    await browser.url("/fixtures/browser/calculator16.html");
    const operators = await browser.react$$("Button", { props: { orange: true } });
    assert.deepEqual(await Promise.all(Array.from(operators, button => button.getText())), [
        "÷",
        "x",
        "-",
        "+",
        "=",
    ]);
});
```
