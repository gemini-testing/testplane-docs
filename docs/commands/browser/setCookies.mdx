# setCookies

## Overview {/* #overview */}

Use the `setCookies` command to set cookies on the current page.

Make sure you are on the page for which you want to set the cookies. You cannot set cookies for an arbitrary page without being on it.

## Usage {/* #usage */}

```javascript
await browser.setCookies(cookies);
```

## Usage Examples {/* #examples */}

```javascript testplane=browser-set-cookies fixture=browser-page
const assert = require("node:assert/strict");

it("should set cookies for the page", async ({ browser }) => {
    await browser.url("/");

    // Set a single cookie.
    await browser.setCookies({
        name: "test1",
        value: "one",
        // Optional parameters:
        // path: "/",                 // cookie path; defaults to "/"
        // domain: "shop.example.com", // defaults to the host of the current page
        // secure: true,              // send only over HTTPS
        // httpOnly: true,            // hide from JavaScript on the page
        // expiry: 1893456000,        // seconds since the Unix epoch
    });

    // Set several cookies at once.
    await browser.setCookies([
        { name: "test2", value: "two" },
        { name: "test3", value: "three" },
    ]);

    const cookies = await browser.getCookies();
    const result = cookies.map(({ name, value, domain }) => ({ name, value, domain }));
    result.sort((a, b) => a.name.localeCompare(b.name));
    console.log(result);
    // For a page on www.example.com:
    // [
    //     { name: "test1", value: "one", domain: "www.example.com" },
    //     { name: "test2", value: "two", domain: "www.example.com" },
    //     { name: "test3", value: "three", domain: "www.example.com" }
    // ]

    const domain = new URL(await browser.getUrl()).hostname;
    assert.deepEqual(result, [
        { name: "test1", value: "one", domain },
        { name: "test2", value: "two", domain },
        { name: "test3", value: "three", domain },
    ]);
});
```
