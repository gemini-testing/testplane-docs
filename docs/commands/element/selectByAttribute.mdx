# selectByAttribute

## Overview {/* #overview */}

Use the `selectByAttribute` command to select an option by a specific attribute value.

## Usage {/* #usage */}

```javascript
await browser.$(selector).selectByAttribute(attribute, value);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>attribute</td><td>String</td><td>The attribute (of the option) by which to select the option.</td></tr>
<tr><td>value</td><td>String or Number</td><td>The value (of the option) by which to select the option.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option name="someName5" value="someValue5">seis</option>
</select>
```

```javascript testplane=element-select-by-attribute fixture=element-html
const assert = require("node:assert/strict");

const select = await browser.$("#selectbox");
assert.equal(await select.getValue(), "someValue0");
await select.selectByAttribute("value", "someValue3");
assert.equal(await select.getValue(), "someValue3");
await select.selectByAttribute("name", "someName5");
assert.equal(await select.getValue(), "someValue5");
```
