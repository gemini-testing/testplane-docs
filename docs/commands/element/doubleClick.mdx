# doubleClick

## Overview {/* #overview */}

Use the `doubleClick` command to perform a double-click on an element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).doubleClick();
```

## Usage Examples {/* #examples */}

**example.html**

```html testplane-html=element-html
<button
    id="myButton"
    ondblclick="document.querySelector('#someText').textContent = 'I was dblclicked'"
>
    Click me
</button>
<div id="someText">I was not clicked</div>
```

**doubleClick.js**

```javascript testplane=element-double-click fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the doubleClick command", async ({ browser }) => {
    const myButton = await browser.$("#myButton");
    await myButton.doubleClick();

    const myText = await browser.$("#someText");
    const value = await myText.getText(); // "I was dblclicked"
    assert.equal(value, "I was dblclicked");
});
```
