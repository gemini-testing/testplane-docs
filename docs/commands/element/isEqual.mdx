# isEqual

## Overview {/* #overview */}

Use the `isEqual` command to compare a specified DOM element with another element.

The command returns `true` if the selected element matches the provided one; otherwise, it returns `false`.

## Usage {/* #usage */}

```javascript
await browser.$(selector).isEqual(el);
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<button id="el">Save</button> <button id="anotherEl">Cancel</button>
```

```javascript testplane=element-is-equal fixture=element-html
const assert = require("node:assert/strict");

it("should detect if an element is equal to another", async ({ browser }) => {
    const el = await browser.$("#el");

    const sameEl = await browser.$("#el");
    const anotherEl = await browser.$("#anotherEl");

    const same = await el.isEqual(sameEl);
    console.log(same); // outputs: true
    assert.equal(same, true);

    const matchesAnother = await el.isEqual(anotherEl);
    console.log(matchesAnother); // outputs: false
    assert.equal(matchesAnother, false);
});
```
