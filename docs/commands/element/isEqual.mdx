# isEqual

## Overview {/* #overview */}

Use the `isEqual` command to compare a specified DOM element with another element.

The command returns `true` if the selected element matches the provided one; otherwise, it returns `false`.

## Usage {/* #usage */}

```javascript
await browser.$(selector).isEqual(el);
```

```javascript testplane=element-is-equal fixture=element-html
const assert = require("node:assert/strict");

const first = await browser.$("#el");
assert.equal(await first.isEqual(await browser.$("#el")), true);
assert.equal(await first.isEqual(await browser.$("#anotherEl")), false);
```
