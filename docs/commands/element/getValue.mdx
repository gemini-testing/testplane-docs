# getValue

## Overview {/* #overview */}

Use the `getValue` command to get the value of a `<textarea>`, `<select>`, or `<input>` element of type `text` for the specified selector.

If multiple elements are found for the given selector, the command will return an array of values.

To get the values of `<input>` elements of type `checkbox` or `radio`, use the [isSelected](../isSelected) command.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getValue();
```

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<input type="text" value="John Doe" id="username" />
```

**getValue.js**

```javascript testplane=element-get-value fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getValue command", async ({ browser }) => {
    const input = await browser.$("#username");
    const value = await input.getValue();
    console.log(value); // outputs: "John Doe"
    assert.equal(value, "John Doe");
});
```
