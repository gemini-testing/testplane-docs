# waitForEnabled

## Overview {/* #overview */}

Use the `waitForEnabled` command to wait until an element becomes enabled or disabled within a specified number of milliseconds.

<Admonition type="warning">
    Unlike other element commands, Testplane will not wait for the element to exist before executing
    this command.
</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).waitForEnabled({ timeout, reverse, timeoutMsg, interval });
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Default**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>timeout</td><td>Number</td><td>500</td><td>Timeout in milliseconds.</td></tr>
<tr><td>reverse</td><td>Boolean</td><td>false</td><td>If _true_, the command will wait for the opposite condition: the element becomes disabled.</td></tr>
<tr><td>timeoutMsg</td><td>String</td><td>_N/A_</td><td>Error message to throw when the timeout is reached.</td></tr>
<tr><td>interval</td><td>Number</td><td>[waitforInterval][wait-for-interval]</td><td>Interval in milliseconds between condition checks.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<button
    id="enable"
    onclick="setTimeout(() => document.querySelector('#save').disabled = false, 100)"
>
    Enable save
</button>
<button id="save" disabled onclick="setTimeout(() => this.disabled = true, 100)">Save</button>
```

**waitForEnabled.js**

```javascript testplane=element-wait-for-enabled fixture=element-html
const assert = require("node:assert/strict");

it("should detect when element is enabled", async ({ browser }) => {
    const save = await browser.$("#save");
    const enable = await browser.$("#enable");

    await enable.click();
    await save.waitForEnabled({ timeout: 3000 });
    assert.equal(await save.isEnabled(), true);
});

it("should detect when element is no longer enabled", async ({ browser }) => {
    const save = await browser.$("#save");
    const enable = await browser.$("#enable");

    await enable.click();
    await save.waitForEnabled({ timeout: 3000 });

    await save.click();
    await save.waitForEnabled({ reverse: true });
    assert.equal(await save.isEnabled(), false);
});
```
