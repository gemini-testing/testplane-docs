# getLocation

## Overview {/* #overview */}

Use the `getLocation` command to determine the location of an element on the page.

The point `(0, 0)` refers to the top left corner of the page.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getLocation(prop);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>prop</td><td>String</td><td>Optional parameter. Can be "x" or "y" to directly get the desired value for simpler checks. If not specified, the command returns an object of the form _\{ x, y }_.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div id="logo" style="position: absolute; left: 150px; top: 20px">Logo</div>
```

```javascript testplane=element-get-location fixture=element-html
const assert = require("node:assert/strict");

const logo = await browser.$("#logo");
assert.deepEqual(await logo.getLocation(), { x: 150, y: 20 });
assert.equal(await logo.getLocation("x"), 150);
assert.equal(await logo.getLocation("y"), 20);
```
