# getLocation

## Overview {/* #overview */}

Use the `getLocation` command to determine the location of an element on the page.

The point `(0, 0)` refers to the top left corner of the page.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getLocation(prop);
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div id="logo" style="position: absolute; left: 150px; top: 20px">Logo</div>
```

```javascript testplane=element-get-location fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getLocation function", async ({ browser }) => {
    const logo = await browser.$("#logo");

    const location = await logo.getLocation();
    console.log(location); // outputs: { x: 150, y: 20 }
    assert.deepEqual(location, { x: 150, y: 20 });

    const xLocation = await logo.getLocation("x");
    console.log(xLocation); // outputs: 150
    assert.equal(xLocation, 150);

    const yLocation = await logo.getLocation("y");
    console.log(yLocation); // outputs: 20
    assert.equal(yLocation, 20);
});
```
