# previousElement

## Overview {/* #overview */}

Use the `previousElement` command to get the previous sibling element of the selected DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).previousElement();
```

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

**previousElement.js**

```javascript testplane=element-previous-element fixture=element-html
const assert = require("node:assert/strict");

it("should get text from previous sibling element", async ({ browser }) => {
    const paragraphs = await browser.$$("p");
    const previousElement = await paragraphs[1].previousElement();

    const text = await previousElement.getText();
    console.log(text); // outputs: "Sibling One"
    assert.equal(text, "Sibling One");
});
```
