# react$

## Overview {/* #overview */}

Use the `react$` command to find React components on the page by their actual name, while filtering them by props and state.

<Admonition type="warning">
Start the search from a DOM element rendered by React, not from the outer mount container. The example below uses React 18.2.

Read more about React selectors in the recipe "[How to use selectors][how-to-use-selectors]".

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).react$(reactComponentSelector, { props, state });
```

## Usage Examples {/* #examples */}

In a calculator with named `Button` components, find each key by its `name` prop.

```javascript testplane=element-react-dollar fixture=element-document
const assert = require("node:assert/strict");

it("should calculate 7 * 6", async ({ browser }) => {
    await browser.url("/fixtures/browser/calculator.html");
    const appWrapper = await browser.$(".calculator");

    await appWrapper
        .react$("Button", {
            props: { name: "7" },
        })
        .click();

    await appWrapper
        .react$("Button", {
            props: { name: "x" },
        })
        .click();

    await appWrapper
        .react$("Button", {
            props: { name: "6" },
        })
        .click();

    await appWrapper
        .react$("Button", {
            props: { name: "=" },
        })
        .click();

    const display = await appWrapper.$(".component-display");
    const value = await display.getText();
    console.log(value); // outputs: "42"
    assert.equal(value, "42");
});
```
