# getHTML

## Overview {/* #overview */}

Use the `getHTML` command to retrieve the HTML source code of a specified DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getHTML(includeSelectorTag);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>includeSelectorTag</td><td>Boolean</td><td>Optional parameter. Include the selector element's tag in the source code. Default: _true_.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<div id="test">
    <span>Lorem ipsum dolor amet</span>
</div>
```

**getHTML.js**

```javascript testplane=element-get-html fixture=element-html
const assert = require("node:assert/strict");

it("should get html for certain elements", async ({ browser }) => {
    const elem = await browser.$("#test");
    const outerHTML = await elem.getHTML();
    console.log(outerHTML);
    // outputs:
    // <div id="test">
    //     <span>Lorem ipsum dolor amet</span>
    // </div>

    const innerHTML = await elem.getHTML(false);
    console.log(JSON.stringify(innerHTML));
    // outputs: "\n    <span>Lorem ipsum dolor amet</span>\n"

    assert.equal(innerHTML, "\n    <span>Lorem ipsum dolor amet</span>\n");
    assert.equal(outerHTML, `<div id="test">${innerHTML}</div>`);
});
```
