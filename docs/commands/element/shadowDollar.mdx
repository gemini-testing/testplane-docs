# shadow$

## Overview {/* #overview */}

Use the `shadow$` command to access an element within the [ShadowRoot][shadow-root] of a given element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).shadow$(shadowSelector);
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div class="input">
    <template shadowrootmode="open">
        <input id="innerEl" value="test123" />
        <input value="second" />
    </template>
</div>
```

```javascript testplane=element-shadow-dollar fixture=element-html
const assert = require("node:assert/strict");

it("should return an element inside a ShadowRoot", async ({ browser }) => {
    const host = await browser.$(".input");
    const innerEl = await host.shadow$("#innerEl");

    const value = await innerEl.getValue();
    console.log(value); // outputs: "test123"
    assert.equal(value, "test123");
});
```
