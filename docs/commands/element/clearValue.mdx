# clearValue

## Overview {/* #overview */}

Use the `clearValue` command to clear the value of an `<input>` or `<textarea>` element.

<Admonition type="warning">
Make sure you can interact with the element before applying this command.

You won't be able to clear the value of an element that is disabled or in read-only mode.

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).clearValue();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<input class="input" />
```

```javascript testplane=element-clear-value fixture=element-html
const assert = require("node:assert/strict");

const input = await browser.$(".input");
await input.setValue("test123");
assert.equal(await input.getValue(), "test123");
await input.clearValue();
assert.equal(await input.getValue(), "");
```
