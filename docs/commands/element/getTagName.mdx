# getTagName

## Overview {/* #overview */}

Use the `getTagName` command to get the tag name of a DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getTagName();
```

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<div id="elem">Lorem ipsum</div>
```

**getTagName.js**

```javascript testplane=element-get-tag-name fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getTagName command", async ({ browser }) => {
    const elem = await browser.$("#elem");
    const tagName = await elem.getTagName();
    console.log(tagName); // outputs: "div"
    assert.equal(tagName, "div");
});
```
