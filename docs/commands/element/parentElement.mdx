# parentElement

## Overview {/* #overview */}

Use the `parentElement` command to get the parent element of the selected DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).parentElement();
```

## Usage Examples {/* #examples */}

**index.html**

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

**parentElement.js**

```javascript testplane=element-parent-element fixture=element-html
const assert = require("node:assert/strict");

it("should get class from parent element", async ({ browser }) => {
    const paragraphs = await browser.$$("p");
    const parent = await paragraphs[2].parentElement();

    const className = await parent.getAttribute("class");
    console.log(className); // outputs: "parent"
    assert.equal(className, "parent");
});
```
