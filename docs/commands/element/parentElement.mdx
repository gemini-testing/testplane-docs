# parentElement

## Overview {/* #overview */}

Use the `parentElement` command to get the parent element of the selected DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).parentElement();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

```javascript testplane=element-parent-element fixture=element-html
const assert = require("node:assert/strict");

const paragraphs = await browser.$$("p");
const parent = await paragraphs[1].parentElement();
assert.equal(await parent.getAttribute("class"), "parent");
```
