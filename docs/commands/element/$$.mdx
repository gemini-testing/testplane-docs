# $$

## Overview {/* #overview */}

Use the `$$` command instead of [findElements][find-elements] as a shorter command to get multiple elements on the page within the scope of an element. This command is similar to the [browser.$$()](../../browser/_dollardollar) command but differs in that the search for elements will be among the children of the current element.

<Admonition type="info">
    Read more about how to select specific elements in the recipe "[How to use
    selectors][how-to-use-selectors]".
</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).$$(subSelector);
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<ul id="menu">
    <li>
        <a href="/">Home</a>
    </li>
    <li>
        <a href="/">Developer Guide</a>
    </li>
    <li>
        <a href="/">API</a>
    </li>
    <li>
        <a href="/">Contribute</a>
    </li>
</ul>
```

```javascript testplane=element-find-all-css fixture=element-html
const assert = require("node:assert/strict");

const menu = await browser.$("#menu");
const items = await menu.$$("li");
assert.equal(await items[2].$("a").getText(), "API");
```

The function selector receives the current `HTMLUListElement` as `this`. Use a regular function, not an arrow function. In TypeScript, you can type the receiver as `function (this: HTMLUListElement)`.

```javascript testplane=element-find-all-function fixture=element-html
const assert = require("node:assert/strict");

const menu = await browser.$("#menu");
const items = await menu.$$(function () {
    return this.querySelectorAll("li");
});
assert.equal(await items[2].$("a").getText(), "API");
```
