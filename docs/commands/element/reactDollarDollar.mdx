# react$$

## Overview {/* #overview */}

Use the `react$$` command to find multiple React components on the page by their actual name, while filtering them by props and state.

<Admonition type="warning">
Start the search from a DOM element rendered by React, not from the outer mount container. The example below uses React 18.2.

Read more about React selectors in the recipe "[How to use selectors][how-to-use-selectors]".

</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).react$$(reactComponentSelector, { props, state });
```

## Usage Examples {/* #examples */}

Find only the calculator keys whose `orange` prop is `true`.

```javascript testplane=element-react-dollar-dollar fixture=element-document
const assert = require("node:assert/strict");

it("should get the orange calculator buttons", async ({ browser }) => {
    await browser.url("/fixtures/browser/calculator.html");
    const appWrapper = await browser.$(".calculator");

    const orangeButtons = await appWrapper.react$$("Button", {
        props: { orange: true },
    });

    const labels = await orangeButtons.map(button => button.getText());
    console.log(labels); // outputs: [ '÷', 'x', '-', '+', '=' ]
    assert.deepEqual(labels, ["÷", "x", "-", "+", "="]);
});
```
