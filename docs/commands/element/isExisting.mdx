# isExisting

## Overview {/* #overview */}

Use the `isExisting` command to determine whether a given DOM element exists.

The command returns `true` if the selected element exists, otherwise it returns `false`.

<Admonition type="warning">
    Unlike other element commands, Testplane will not wait for the element to exist before executing
    this command.
</Admonition>

## Usage {/* #usage */}

```javascript
await browser.$(selector).isExisting();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div id="visible">Visible</div>
<div id="notDisplayed" style="display: none">Hidden</div>
<div id="notVisible" style="visibility: hidden">Hidden</div>
<div id="notInViewport" style="position: absolute; left: 10000px">Off screen</div>
<div id="zeroOpacity" style="opacity: 0">Transparent</div>
```

```javascript testplane=element-is-existing fixture=element-html
const assert = require("node:assert/strict");

assert.equal(await browser.$("#visible").isExisting(), true);
assert.equal(await browser.$("#notDisplayed").isExisting(), true);
assert.equal(await browser.$("#notVisible").isExisting(), true);
assert.equal(await browser.$("#notExisting").isExisting(), false);
assert.equal(await browser.$("#notInViewport").isExisting(), true);
assert.equal(await browser.$("#zeroOpacity").isExisting(), true);
```
