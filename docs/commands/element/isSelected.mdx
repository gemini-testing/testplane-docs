# isSelected

## Overview {/* #overview */}

Use the `isSelected` command to determine whether a given `<option>` or `<input>` element of type `checkbox` or `radio` is selected.

The command returns `true` if the element is selected; otherwise, it returns `false`.

## Usage {/* #usage */}

```javascript
await browser.$(selector).isSelected();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select name="selectbox" id="selectbox">
    <option value="John Doe">John Doe</option>
    <option value="Layla Terry" selected="selected">Layla Terry</option>
    <option value="Bill Gilbert">Bill Gilbert</option>
</select>
```

```javascript testplane=element-is-selected fixture=element-html
const assert = require("node:assert/strict");

assert.equal(await browser.$('[value="Layla Terry"]').isSelected(), true);
assert.equal(await browser.$('[value="Bill Gilbert"]').isSelected(), false);
```
