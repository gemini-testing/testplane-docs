# getComputedLabel

## Overview {/* #overview */}

Use the `getComputedLabel` command to get the computed [WAI-ARIA][wai-aria] label of an element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getComputedLabel();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select name="q" aria-label="Search">
    <option>All</option>
</select>
```

```javascript testplane=element-get-computed-label fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getComputedLabel command", async ({ browser }) => {
    const elem = await browser.$('[name="q"]');
    const label = await elem.getComputedLabel();
    console.log(label); // outputs: "Search"
    assert.equal(label, "Search");
});
```
