# dragAndDrop

## Overview {/* #overview */}

Use the `dragAndDrop` command to drag an element to a specified target element or position.

## Usage {/* #usage */}

```javascript
await browser.$(selector).dragAndDrop(target, { duration });
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>target</td><td>Element or DragAndDropCoordinate</td><td>Target element or an object with _x_ and _y_ coordinates.</td></tr>
<tr><td>duration</td><td>Number</td><td>Timeout for dragging the element _(drag operation)_.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

Drag the tile onto a target of the same size, then move it 100 pixels right and 200 pixels down.

```javascript testplane=element-drag-and-drop fixture=element-drag
const assert = require("node:assert/strict");

const tile = await browser.$("#someElem");
const target = await browser.$("#someTarget");
await tile.dragAndDrop(target);
assert.deepEqual(await tile.getLocation(), await target.getLocation());

const { x, y } = await tile.getLocation();
await tile.dragAndDrop({ x: 100, y: 200 });
assert.deepEqual(await tile.getLocation(), { x: x + 100, y: y + 200 });
```
