# selectByVisibleText

## Overview {/* #overview */}

Use the `selectByVisibleText` command to select an option by its displayed text.

## Usage {/* #usage */}

```javascript
await browser.$(selector).selectByVisibleText(text);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>text</td><td>String or Number</td><td>The text (of the option) by which to select the option.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option value="someValue5">seis</option>
</select>
```

```javascript testplane=element-select-by-visible-text fixture=element-html
const assert = require("node:assert/strict");

const select = await browser.$("#selectbox");
assert.equal(await select.$("option:checked").getText(), "uno");
await select.selectByVisibleText("cuatro");
assert.equal(await select.$("option:checked").getText(), "cuatro");
```
