# getSize

## Overview {/* #overview */}

Use the `getSize` command to get the width and height of a DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getSize(prop);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>prop</td><td>String</td><td>Optional parameter. The size to retrieve: "width" or "height". If not specified, the command will return an object of the form _\{ width, height }_.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div id="logo" style="width: 32px; height: 32px">Logo</div>
```

```javascript testplane=element-get-size fixture=element-html
const assert = require("node:assert/strict");

it("should demonstrate the getSize command", async ({ browser }) => {
    const logo = await browser.$("#logo");

    const size = await logo.getSize();
    console.log(size); // outputs: { width: 32, height: 32 }
    assert.deepEqual(size, { width: 32, height: 32 });

    const width = await logo.getSize("width");
    console.log(width); // outputs: 32
    assert.equal(width, 32);

    const height = await logo.getSize("height");
    console.log(height); // outputs: 32
    assert.equal(height, 32);
});
```
