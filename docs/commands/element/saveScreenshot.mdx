# saveScreenshot

## Overview {/* #overview */}

Use the `saveScreenshot` command to save a screenshot of an element to a PNG file.

## Usage {/* #usage */}

```javascript
await browser.$(selector).saveScreenshot(filepath);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>filepath</td><td>String</td><td>The path to the screenshot relative to the execution directory (the .png extension is mandatory).</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

Save just the badge, not the entire viewport. The destination directory must exist.

```javascript testplane=element-save-screenshot fixture=element-screenshot
const badge = await browser.$("#badge");
await badge.saveScreenshot(`./artifacts/badge-${browser.sessionId}.png`);
```
