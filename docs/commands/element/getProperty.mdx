# getProperty

## Overview {/* #overview */}

Use the `getProperty` command to retrieve a property of an element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getProperty(property);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>property</td><td>String</td><td>The name of the element's property.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```javascript testplane=element-get-property fixture=element-document
const assert = require("node:assert/strict");

it("should demonstrate the getProperty command", async ({ browser }) => {
    const elem = await browser.$("body");
    const tag = await elem.getProperty("tagName");
    console.log(tag); // outputs: "BODY"
    assert.equal(tag, "BODY");
});
```
