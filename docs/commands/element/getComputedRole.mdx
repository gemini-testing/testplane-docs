# getComputedRole

## Overview {/* #overview */}

Use the `getComputedRole` command to get the computed [WAI-ARIA][wai-aria] role of an element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).getComputedRole();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select name="q" aria-label="Search">
    <option>All</option>
</select>
```

```javascript testplane=element-get-computed-role fixture=element-html
const assert = require("node:assert/strict");

const field = await browser.$('[name="q"]');
assert.equal(await field.getComputedRole(), "combobox");
```
