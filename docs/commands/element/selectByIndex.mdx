# selectByIndex

## Overview {/* #overview */}

Use the `selectByIndex` command to select an option by a specific index.

## Usage {/* #usage */}

```javascript
await browser.$(selector).selectByIndex(index);
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>index</td><td>Number</td><td>The index (of the option) by which to select the option.</td></tr>

</tbody>
</table>

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<select id="selectbox">
    <option value="someValue0">uno</option>
    <option value="someValue1">dos</option>
    <option value="someValue2">tres</option>
    <option value="someValue3">cuatro</option>
    <option value="someValue4">cinco</option>
    <option value="someValue5">seis</option>
</select>
```

```javascript testplane=element-select-by-index fixture=element-html
const assert = require("node:assert/strict");

const select = await browser.$("#selectbox");
assert.equal(await select.getValue(), "someValue0");
await select.selectByIndex(4);
assert.equal(await select.getValue(), "someValue4");
```
