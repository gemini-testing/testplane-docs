# nextElement

## Overview {/* #overview */}

Use the `nextElement` command to get the next sibling element of the selected DOM element.

## Usage {/* #usage */}

```javascript
await browser.$(selector).nextElement();
```

## Usage Examples {/* #examples */}

```html testplane-html=element-html
<div class="parent">
    <p>Sibling One</p>
    <p>Sibling Two</p>
    <p>Sibling Three</p>
</div>
```

```javascript testplane=element-next-element fixture=element-html
const assert = require("node:assert/strict");

const paragraphs = await browser.$$("p");
const sibling = await paragraphs[1].nextElement();
assert.equal(await sibling.getText(), "Sibling Three");
```
