# respondOnce

## Overview {/* #overview */}

Use the `respondOnce` command to respond once with the specified overwrite.

You can call `respondOnce` multiple times in succession. The responses will be used in the same order the `respondOnce` commands were called.

If you use only `respondOnce` and access the resource more times than `respondOnce` was called, then after exhausting the fake data, the request will start returning the original response from the resource.

<Admonition type="info">
    Also read the recipe "[How to Track and Intercept Network Requests and
    Responses][how-to-intercept-requests-and-responses]".
</Admonition>

## Usage {/* #usage */}

```javascript
mock.respondOnce(overwrites, { headers, statusCode, fetchResponse });
```

## Usage Examples {/* #examples */}

The todo page fetches its list on every visit. In this WebDriver BiDi example, the list shrinks three times; the fourth visit displays the server’s original list.

```javascript testplane=mock-respond-once fixture=matchers-intercept
async function getTodoTitles(browser) {
    // Wait for the list from this page load, then read its items in order.
    const firstTodo = await browser.$("#todo-list li");
    await firstTodo.waitForExist();
    const items = await browser.$$("#todo-list li");
    return Promise.all(items.map(item => item.getText()));
}

it("uses the queued responses before falling back to the real list", async ({ browser }) => {
    const todos = await browser.mock("/fixtures/matchers/todos.json", { method: "GET" });
    // Queue three different lists on the same mock.
    todos.respondOnce([{ title: "3" }, { title: "2" }, { title: "1" }]);
    todos.respondOnce([{ title: "2" }, { title: "1" }]);
    todos.respondOnce([{ title: "1" }]);

    // Each visit makes one GET request and consumes the next list.
    const page = "/fixtures/matchers/todos.html";
    await browser.url(page);
    const firstList = await getTodoTitles(browser);
    expect(firstList).toEqual(["3", "2", "1"]);

    await browser.url(page);
    const secondList = await getTodoTitles(browser);
    expect(secondList).toEqual(["2", "1"]);

    await browser.url(page);
    const thirdList = await getTodoTitles(browser);
    expect(thirdList).toEqual(["1"]);

    // No overwrites remain: this is the actual resource response.
    await browser.url(page);
    const originalList = await getTodoTitles(browser);
    expect(originalList).toEqual(["Original todo"]);
});
```
