# requestOnce

## Overview {/* #overview */}

Override only the next matching outgoing request. Equivalent to `mock.request(overwrite, true)`.

## Usage {/* #usage */}

`mock.requestOnce(overwrite)`

## Parameters {/* #parameters */}

| **Parameter**       | **Type**                             | **Default** | **Description**                                                                                         |
| ------------------- | ------------------------------------ | ----------- | ------------------------------------------------------------------------------------------------------- |
| `overwrite`         | `object`                             | Required    | Request fields to override.                                                                             |
| `overwrite.body`    | `unknown \| Function`                | —           | Request body; strings are sent as text, objects as JSON. Falsy body values are ignored in this version. |
| `overwrite.cookies` | `Cookie[] \| Function`               | —           | Cookie list in WebDriver cookie format.                                                                 |
| `overwrite.headers` | `Record<string, string> \| Function` | —           | Replacement header map, not a merge with the original headers.                                          |
| `overwrite.method`  | `string \| Function`                 | —           | HTTP method, for example `POST`.                                                                        |
| `overwrite.url`     | `string \| Function`                 | —           | Absolute replacement URL.                                                                               |

## Result {/* #result */}

The same mock object, synchronously, for chaining.

## Limitations {/* #limitations */}

Requires a WebDriver BiDi session (`webSocketUrl: true`); this method is not provided by the Classic/CDP mock implementation. The examples explicitly subscribe to network events in every session; see [the subscription limitation](./waitForResponse.mdx#limitations). Always call `mock.restore()` in `finally` when the mock is no longer needed.

The override affects outgoing requests; it does not fabricate responses. Each field may be a value or a synchronous function receiving the BiDi request event (the URL is in `event.request.url`). Request overrides, redirects and aborts share one rule queue. A persistent rule replaces that queue; a one-shot rule keeps existing one-shot rules but removes a persistent rule. Do not expect a persistent rule to resume after a one-shot rule.

## Example {/* #examples */}

Use a local HTTP test site as `baseUrl`. `/` serves HTML. `/api/items` returns JSON with `source: "original"`, the request method in `method`, and the `x-example` request header in `header` (`null` when absent). `/api/other` returns the same fields with `source: "redirected"`. The examples use real requests to these endpoints.

```javascript
const assert = require("node:assert/strict");

it("mock.requestOnce: change only the next request", async ({ browser }) => {
    await browser.url("/");
    await browser.sessionSubscribe({
        events: ["network.beforeRequestSent", "network.responseStarted"],
    });
    const mock = await browser.mock("/api/items");
    try {
        mock.requestOnce({ headers: { "x-example": "once" } });
        const first = await browser.execute(async () =>
            (await fetch("/api/items", { cache: "no-store" })).json(),
        );
        const second = await browser.execute(async () =>
            (await fetch("/api/items", { cache: "no-store" })).json(),
        );
        assert.equal(first.header, "once");
        assert.equal(second.header, null);
    } finally {
        await mock.restore();
    }
});
```
