# restore

## Overview {/* #overview */}

Use the `restore` command to perform all actions that [mock.clear()](../clear) does, as well as remove any fake return values or implementations.

## Usage {/* #usage */}

```javascript
mock.restore();
```

## Usage Examples {/* #examples */}

In this WebDriver BiDi example, `#reload` fetches `/api/items` and `#source` displays the result.

```javascript testplane=mock-restore fixture=matchers-network
const mock = await browser.mock("/api/items");
mock.respond({ source: "mocked" });
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("mocked");

await mock.restore();
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("original");
```
