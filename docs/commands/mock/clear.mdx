# clear

## Overview {/* #overview */}

Use the `clear` command to reset all information stored in the `mock.calls` array.

## Usage {/* #usage */}

```javascript
mock.clear();
```

## Usage Examples {/* #examples */}

In this WebDriver BiDi example, `#reload` fetches `/api/items` and `#source` displays the result.

```javascript testplane=mock-clear fixture=matchers-network
const mock = await browser.mock("/api/items");
await browser.$("#reload").click();
await mock.waitForResponse();

expect(mock.calls).toHaveLength(1);
mock.clear();
expect(mock.calls).toHaveLength(0);
```
