# clear

## Overview {/* #overview */}

Use the `clear` command to reset all information stored in the `mock.calls` array.

## Usage {/* #usage */}

```javascript
mock.clear();
```

## Usage Examples {/* #examples */}

Record a navigation, clear the history, and visit the page again in a WebDriver BiDi session:

```javascript testplane=mock-clear fixture=matchers-intercept
it("clears the recorded calls and keeps recording", async ({ browser }) => {
    const page = await browser.mock("/fixtures/matchers/tasks.html");
    await browser.url("/fixtures/matchers/tasks.html");
    await page.waitForResponse();

    // One navigation was recorded; clear its history without removing the mock.
    expect(page.calls).toHaveLength(1);
    page.clear();
    expect(page.calls).toHaveLength(0);

    // The next navigation starts a new history.
    await browser.url("/fixtures/matchers/tasks.html");
    await page.waitForResponse();
    expect(page.calls).toHaveLength(1);
});
```
