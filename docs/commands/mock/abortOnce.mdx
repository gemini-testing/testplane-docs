# abortOnce

## Overview {/* #overview */}

Use the `abortOnce` command to abort a request once.

In a WebDriver BiDi session, call `mock.abortOnce()` without an error code. In a CDP session, specify one of these errors:

-   Failed
-   Aborted
-   TimedOut
-   AccessDenied
-   ConnectionClosed | ConnectionReset | ConnectionRefused | ConnectionAborted | ConnectionFailed
-   NameNotResolved
-   InternetDisconnected
-   AddressUnreachable
-   BlockedByClient | BlockedByResponse

## Usage {/* #usage */}

```javascript
mock.abortOnce(errorCode);
```

## Usage Examples {/* #examples */}

In this WebDriver BiDi example, `#reload` fetches `/api/items` and `#source` displays the result.

```javascript testplane=mock-abort-once fixture=matchers-network
const mock = await browser.mock("/api/items");
mock.abortOnce();

await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("Unavailable");
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("original");
```

In a CDP session, you can specify the network failure:

```javascript testplane=mock-abort-once-cdp fixture=matchers-network transport=cdp
const mock = await browser.mock("**/api/items");
mock.abortOnce("TimedOut");

await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("Unavailable");
await browser.$("#reload").click();
await expect(browser.$("#source")).toHaveText("original");
```
