# respond

## Overview {/* #overview */}

Use the `respond` command to always reply with the same overwrite.

<Admonition type="info">
    Also read the recipe "[How to Track and Intercept Network Requests and
    Responses][how-to-intercept-requests-and-responses]".
</Admonition>

## Usage {/* #usage */}

```javascript
mock.respond(overwrites, { headers, statusCode, fetchResponse });
```

## Command Parameters {/* #parameters */}

<table>
<thead>
<tr><td>**Name**</td><td>**Type**</td><td>**Description**</td></tr>
</thead>
<tbody>
<tr><td>overwrites</td><td>MockOverwrite</td><td>_Payload_ to overwrite the response.</td></tr>

</table>

## Usage Examples {/* #examples */}

In this WebDriver BiDi example, `#reload` fetches `/api/items` and `#source` displays the result.

```javascript testplane=mock-respond fixture=matchers-network
const mock = await browser.mock("/api/items", { method: "GET" });
mock.respond({ source: "saved list" }, { statusCode: 200 });

for (let i = 0; i < 2; i++) {
    await browser.$("#reload").click();
    await expect(browser.$("#source")).toHaveText("saved list");
}
```

In a CDP session you can build the response body from the request. Here the Save button sends JSON containing a `title`. The WebDriver BiDi transport does not support a function as the response body.

```javascript testplane=mock-respond-dynamic fixture=matchers-network transport=cdp
const mock = await browser.mock("**/api/items", { method: "POST" });
mock.respond(request => ({ source: JSON.parse(request.postData).title }), {
    statusCode: 201,
    headers: { "Content-Type": "application/json" },
    fetchResponse: false,
});

await browser.$("#save").click();
await expect(browser.$("#source")).toHaveText("Ship feature");
```
